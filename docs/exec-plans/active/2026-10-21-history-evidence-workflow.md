## A: hit to evidence / A：命中到证据

### Evaluation before benefit claims / 效果声明前的评估

Prepare 6–8 private, reference-backed development questions from current code/behavior, without providing the answer's historical identifiers. Freeze worker prompts separately from the private evidence key, corpus, source revision, guide, model/effort, environment and budgets. Keep raw-log search as a strong control. First establish the archived current-version baseline; then run a paired comparison for one named change with the same model/tasks/environment. Do not silently substitute synthetic trials, shared worker memory, supplied locators or a changed corpus. / 从当前代码／行为准备 6–8 个有私有参考依据的开发问题，不提供答案所需历史标识。冻结 worker 问题，并与私有答案键、语料、源码版本、指南、模型／effort、环境及预算分开保存；保留原始日志搜索强对照。先建立归档当前版本基线，再对一项具名改动进行同模型／任务／环境配对比较。不能静默以合成试跑、共享 worker 记忆、预给定位符或变更语料代替。

Cover four task families: / 覆盖四类任务：

1. Weak current clues lead to an earlier name/path/test and a more precise next query. / 当前弱线索引出旧名称／路径／测试，再形成更精确查询。
2. Essential evidence lies in the middle/tail of a long output, patch or compound event. / 关键依据位于长输出、patch 或复合事件中部／尾部。
3. Constraints and implementation span explicit parent/child relationships or a later superseding decision; distinguish inherited copies and independent attempts. / 约束与实施跨明确父子关系或后续改变决定的记录，区分继承副本与独立尝试。
4. The delivered entry opens the supporting content and permits continued reading. Verify target identity, viewer readiness, visible support and continuation separately from browser launch request. / 交付入口打开支持结论的内容并可继续阅读；分别验证目标身份、查看页就绪、可见支撑及续读，不能以浏览器启动请求代替。

Grade failures by layer: evidence absent from corpus → not retrieved → retrieved but not displayed → displayed but not understood/continued → read but judged incorrectly → correct conclusion delivered at the wrong location. Allow unknown/unassessed layers; do not infer cognition from a command name. Record actual forwarded guide content/truncation and retrieval text, not only that a file/read command ran. / 按层归因：证据未纳入语料 → 未检索到 → 已找到但未展示 → 展示后未理解／未续读 → 已读但判断错误 → 判断正确但交付位置错误。允许未知／未评层，不能由命令名推断理解。记录实际转发的指南内容／截断和检索文本，而非只记录执行过文件读取。

First-read latency, search/read ratio and duplicate candidates explain behavior; they are not quality gates. Keep indexing/query work, response payload and actual model usage separate; unavailable usage stays null. Public fixtures are minimized synthetic/sanitized data; real prompts, keys, transcripts and trial logs remain private and ignored. / 首次 read 时延、搜索／读取比及重复候选用于解释行为，不作为质量门槛。索引／查询工作、返回载荷及实际模型用量分开；不可得用量保持 null。公开 fixture 仅使用最小合成／脱敏数据；真实题目、答案键、转录和试跑日志留在私有忽略目录。

### Minimal read contract / 最小读取契约

- Add explicit `aroundHit: {before, after}` to existing `read`; both values are nonnegative safe integers, total window at most 100,000 UTF-16 code units including the anchor unit. Omitted `parts` selects projection; explicitly supplied parts must normalize to projection only. / 在现有 `read` 增加显式选项；两值均为非负安全整数，含锚点码元的总窗口最多 100,000 个 UTF-16 码元。省略 parts 时选择投影，显式 parts 必须归一化为仅投影。
- Use each selected reference's stored hit offset independently. No new MatchRef, query re-search or detail/HTML/Raw coordinate mapping. Missing hit offsets return an explicit error, while zero is valid. / 分别使用各选中引用已存命中偏移；不新增 MatchRef、不重新搜索、不映射详情／HTML／Raw 坐标。缺少偏移明确报错，零偏移合法。
- Reject incompatible source/offset/length/textFormat inputs. Return actual interval, total length, before/after availability and executable range continuation. A centered excerpt is a starting point, not complete evidence. / 拒绝不兼容输入；返回实际区间、总长、前后可读性及可执行范围续读。命中附近摘录是阅读起点，不代表完整依据。
- Keep existing defaults, selected-item validation, source verification, compact/durable refs, item pagination and byte-budget admission. Compute per-item windows in the existing loop; defer heterogeneous per-item request shapes unless tasks demonstrate a need. / 保持既有默认值、选中项校验、来源核验、紧凑／持久引用、逐项分页及字节预算准入。在现有循环计算逐项窗口；除非任务证明必要，暂不引入异构逐项请求结构。
