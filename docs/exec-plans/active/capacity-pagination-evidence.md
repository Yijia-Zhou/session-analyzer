# Capacity group 5 evidence / 容量第 5 组证据

Baseline / 基线: `6e84bb09876561ced0b060e68f3ee5da173614a5`, branch `capacity/seven-groups`.

- Confirmed: both HTTP event routes and shared query-filter parsing clamped offsets to 1,000,000. The previous timeline response also omitted the revision, so a later page could silently use a replaced index. / 已确认：两个 HTTP 事件端点及共享查询筛选解析均将 offset 钳制到 1,000,000。此前时间线响应也不携带修订，因此后续页可能静默使用被替换的索引。
- Implemented: one shared exact safe-integer parser; omitted offset = 0; invalid decimal syntax, fractions, negatives, or unsafe integers = HTTP 400 `INVALID_PAGINATION`; beyond-end pages retain their exact requested offset. Positive safe-integer page sizes remain capped at 500 (timeline) / 100 (file activity), defaults 150 / 50. Missing values now actually use the documented defaults rather than Number(null) becoming zero. / 已实现：统一的精确安全整数解析；省略 offset 为零；非法十进制写法、小数、负数或非安全整数返回 HTTP 400 `INVALID_PAGINATION`；尾部之外空页保留原请求位置。正安全整数页长仍限制为时间线 500／文件活动 100，默认 150／50。省略参数正确使用默认值，不再由 Number(null) 变成零。
- Implemented: optional revision precondition in both endpoints, HTTP 409 `INDEX_REVISION_RETIRED` on mismatch, revision-bearing timeline responses, browser request pinning and response position/revision validation. Omitted preconditions intentionally query the current revision; clients paging a snapshot must send the returned revision. Existing in-flight lease cancellation remains authoritative. / 已实现：两个端点的可选修订前置条件；不匹配返回 HTTP 409 `INDEX_REVISION_RETIRED`；时间线响应携带修订；浏览器固定请求修订并验证响应位置与修订。未提供条件时有意查询当前修订；跨页固定快照的客户端必须发送响应修订。既有进行中 lease 取消仍保持权威。
- Validation performed: 31 focused Node tests passed (`query-pagination`, `session-query-store`, `index-revision-server`); two Chromium cases passed (large file-activity offset, mismatched-page refusal, normal Timeline/Trajectory file paging and return). Rebuilt browser source and `build-client --check` passed. HTTP covers 999999 / 1000000 / 1000001 / 1000500 / MAX_SAFE_INTEGER, invalid inputs, defaults, page budgets, and real index replacement. These large positions use empty pages of a real source-backed synthetic index; this is exact-position evidence, not a million-event materialization capacity claim. / 已执行验证：31 个聚焦 Node 测试通过；两个 Chromium 用例通过（大文件活动 offset、拒收错页、正常 Timeline／Trajectory 文件分页与返回）。已从源码重建浏览器且 build check 通过。HTTP 覆盖旧界限内／等于／外、1000500、MAX_SAFE_INTEGER、非法输入、默认值、页长预算和真实索引替换。大位置使用真实来源支持的合成索引空页；这是精确位置证据，不宣称已证明百万事件物化容量。
- Packaging: new shared module is already included by `package.json#files` entry `src/shared/`. No dependency added. / 包装：新共享模块已由 `package.json#files` 的 `src/shared/` 条目包含，未增加依赖。
