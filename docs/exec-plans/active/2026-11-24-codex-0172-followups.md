## Implementation record / 实施记录

- **Code Mode.** Generation-qualified cell IDs now retain their full spelling on pending receipts and waits. All three uniquely matched waits in the targeted real file joined their original execution, with 12/12 Raw checks. Four reader paths counted three operations in the synthetic fixture (previously four). History CLI found the recovered output on the original operation. 46 focused Node tests and the bilingual Chromium multi-wait scenario passed. Host reconnect was not forced. / 新版 cell ID 按完整代次关联。定向真实文件中 3/3 次等待归回原操作，12/12 次 Raw 回查一致。合成四路径、CLI 和双语浏览器验证通过，未主动触发主机重连。

The targeted local cell probe selects the first eligible file within its budget. A later run found six uniquely owned waits in the selected file and read back all 24 physical records. File selection can change as sessions are written. These counts belong to the individual runs. / 定向探针在预算内取首个合格文件，后一次运行在选中文件中验证 6 次唯一等待及 24 条物理记录。会话持续写入时样本可变，次数按单次运行解释。

## Original sequencing and remaining evidence / 原定次序与待补证据

At the audit baseline, 11 files contained matching generation-qualified receipt/wait IDs. A real cold read split 3/3 uniquely matched waits, and the four-path synthetic control exhibited the same error. This set the priority for the cell fix. The archived-ancestor cases required a separate storage review. / 审计基线中有 11 个文件观察到同一带代次的回执与等待 ID。一次真实冷读取把 3/3 次可唯一归属的等待拆开，四路径合成对照也重现错误，据此优先修复 cell。归档祖先由独立存储审查验收。

Prioritize real-client captures of scoped MCP failure, host reconnect, file-only generation and new speech frames. A controlled imported fixture can demonstrate a reader failure while the natural writer frequency stays unknown. Check complete, incomplete and legacy variants before broadening projection. Keep upstream-only search, model catalog, private subscriber notifications, opaque model ID allocations and generated metadata out of the default Main event list unless a separate user-visible need is demonstrated. / 优先补充跨环境 MCP、host 重连、仅文件引用出图和新版语音实样。合成 reader 反例与自然使用频率分别说明；无新增用户语义的客户端、传输及内部状态变化保持现有证据层。
