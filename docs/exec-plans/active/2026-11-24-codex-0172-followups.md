## Acceptance units / 独立验收单元

Each row can ship independently except for its listed prerequisite. Convert the smallest case from the linked manual probes into a focused regression **before** changing production behavior. Validate Raw identity, event counts and actual search results on uncompacted, compact, cold materialized and verified reuse paths. For Main/detail changes, add bilingual Timeline/Trajectory and History CLI checks, with an older input as a negative control. / 除注明前置条件外可分别交付。先将最小反例转成回归，再改生产逻辑；四条读取路径均验物理 Raw、事件数与检索结果。涉及主层或详情时验双语两种视图、CLI 及旧输入对照。

## Evidence still needed / 待补证据

Start with the generation-qualified cell fix: 11 files contain matching receipt/wait IDs, a dedicated real cold read split 3/3 uniquely matched waits, and the four-path synthetic control reproduces the same ownership error. Next handle explicit message/side-boundary ownership. Keep the alternate-ancestor change separate for storage review. File-backed image completion has a small independent patch surface. Scope-tagged MCP and speech frames have synthetic evidence but no matching local feature capture, so they can follow these increments. / 建议先修复经 11 个文件同 ID 观测、1 个真实文件 3/3 次唯一等待归属错误及四路径合成对照支持的 cell 归属，再处理消息来源与旁聊边界。祖先副本需独立存储审查，文件型出图可独立小步修复。跨环境 MCP 与语音帧缺少本地触发实样，可随后安排。

Prioritize real-client captures of scoped MCP failure, host reconnect, file-only generation and new speech frames. A controlled imported fixture can demonstrate a reader failure while the natural writer frequency stays unknown. Check complete, incomplete and legacy variants before broadening projection. Keep upstream-only search, model catalog, private subscriber notifications, opaque model ID allocations and generated metadata out of the default Main event list unless a separate user-visible need is demonstrated. / 优先补充跨环境 MCP、host 重连、仅文件引用出图和新版语音实样。合成 reader 反例与自然使用频率分别说明；无新增用户语义的客户端、传输及内部状态变化保持现有证据层。
