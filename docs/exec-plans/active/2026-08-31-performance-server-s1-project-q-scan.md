## Attribution model / 归因模型

M0 separates: eligible Session selection; packed metadata traversal; text-chunk access and codec/byte accounting; gunzip and frame/string materialization; `q` hit detection; matching-Event/matching-Session/latest selection aggregation; and latest-result snippet/label/DTO hydration. / M0 分离：eligible 会话选择；packed metadata traversal；text chunk 访问与 codec/byte accounting；gunzip 与 frame/string materialization；`q` 命中检测；匹配事件、匹配会话与 latest selection 聚合；以及 latest result 的 snippet/label/DTO hydration。

The profiler compares metadata-only traversal, text materialization with a no-op visitor, pure predicate work on profiler-local decoded rows, aggregation on precomputed hit booleans, and the actual observer-absent production Project Scope query on the same immutable built Index. Wall-clock differences are descriptive, not exact causal subtraction; deterministic operation counts are authoritative. / Profiler 在同一个不可变 built Index 上比较 metadata-only traversal、no-op visitor 的文本物化、profiler-local decoded row 上的纯 predicate 工作、预计算 hit boolean 上的聚合，以及 observer 缺席的实际生产项目范围查询。Wall-clock 差值只作描述，不作为精确因果减法；确定性 operation count 才是权威。

### M1 recommendation and rejected alternatives / M1 建议与被拒绝替代方案

Preferred single M1 boundary: **short-circuit boolean q-hit detection at the Project Scope Event predicate boundary**. M1 should decide the smallest exact placement (Project Scope-specific or safely shared), preserve case-insensitive whitespace-phrase semantics and snippet behavior, and add no cache or retained structure. M0 does not implement this. / 唯一首选 M1 boundary：**在项目范围 Event predicate boundary 进行 short-circuit boolean q-hit detection**。M1 应决定最小的精确放置位置（项目范围专用或安全共享），保持大小写不敏感的 whitespace-phrase 语义与 snippet 行为，并且不增加 cache 或 retained structure。M0 不实施该方案。

Rejected for M1: exact repeated-query reuse and query-extension reuse (unmeasured repetition benefit plus cache identity/invalidation/abort and retained-result risks); chunk-level negative metadata (schema, build, invalidation, and retained-memory cost); text-first/byte-level scanning (larger correctness surface); worker pools, persistent databases, cursors, and any new Materialized Session cache (out of scope and unsupported by evidence). / M1 拒绝：exact repeated-query reuse 与 query-extension reuse（重复收益未测量，并引入 cache identity／invalidation／abort 与 retained-result 风险）；chunk-level negative metadata（schema、build、invalidation 与 retained-memory 成本）；text-first／byte-level scanning（更大的正确性面）；worker pool、持久化数据库、cursor 与任何新的 Materialized Session cache（超出范围且无证据支持）。

A full inverted index or any additional large retained structure is explicitly rejected. The accepted store already accounts for 1,360,674,546 bytes on this corpus; M0 does not justify adding postings proportional to rows/terms/occurrences, so no implementation or speculative memory budget is authorized. / 明确拒绝完整倒排索引或任何额外大型 retained structure。接受的 store 在该语料上已 accounted 1,360,674,546 bytes；M0 没有依据增加随 row／term／occurrence 扩展的 posting，因此不授权实现或推测性内存预算。
