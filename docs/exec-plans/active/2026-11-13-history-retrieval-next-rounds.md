## Agreed rules / 已商定规则

1. **Evidence gate.** A new retrieval capability must target an observed failure and either lower cost, latency or usage burden at equal evidence quality, or clearly improve evidence completeness at equal budget. Completeness and correctness are assessed before cost. / **证据门槛。** 新增检索能力必须针对已观察到的失败，并在同等证据质量下降低成本、时延或使用负担，或在同等预算下明显提高证据完整度。先评完整度与正确性，再比成本。
2. **Two acceptance tiers.** Deterministic behavior and local cost are accepted by deterministic checks. Any claim about agents completing whole tasks needs a controlled agent comparison. A passing deterministic check never becomes an end-to-end claim. / **两级验收。** 确定性行为与局部成本以确定性检查验收；凡涉及 agent 完成整题的主张，必须有受控 agent 对照。确定性检查通过不得扩写成端到端主张。
3. **Reference rules before persistence.** The minimal identity, invalidation and version rules are written before any persisted index format is designed. A cache key need not equal a reference key. / **引用规则先于持久化。** 先写定最小身份、失效与版本规则，再设计任何持久化索引格式。缓存键不必等于引用键。
4. **One bundle, one comparison.** Round 1 is evaluated as a named bundle; per-change attribution is reported separately and only when a split comparison exists. / **整包对照。** 第一轮作为具名组合评估；单项归因单独报告，且仅在有拆分对照时给出。

### Reference behavior matrix / 引用行为矩阵

Target behavior, not current behavior: / 目标行为，非现状：

| Change / 变化 | Reference / 引用 | Cache or index / 缓存或索引 |
| --- | --- | --- |
| Restart only; source and interpretation unchanged / 仅重启，来源与解释未变 | Durable evidence references reverify; short handles and cursors may expire / 持久证据引用可重新核验；短句柄与游标可过期 | Reuse / 复用 |
| Independent records appended to the same Session / 同会话追加独立记录 | References to unchanged events stay valid / 未变事件的引用继续有效 | Update the affected Session or dependency / 更新受影响会话或依赖 |
| A later tool result changes a Logical Event / 工具结果后到，逻辑事件内容改变 | See the precedence rule below / 见下方优先级规则 | New event and projection version / 新事件及投影版本 |
| Source rewritten, truncated or deleted / 来源被改写、截断或删除 | Old content is readable only if retained; otherwise explicitly unavailable / 仅在保留旧内容时可读，否则明确不可用 | Invalidate and rebuild the affected part / 失效并重建受影响部分 |

| Identical content occurs twice / 完全相同的内容重复发生 | The two occurrences remain distinguishable / 两次发生仍可区分 | Never merge events by content hash alone / 不单凭内容哈希合并事件 |

Rules: / 规则：

- **Following an update is an explicit request.** `contextRef` binds a service snapshot and resolves short handles; omitting it does not mean that a new version may be returned. An ordinary read of a durable reference stays a strict verification, with or without a context. Only an explicit request to follow updates may enter a new version; it must report the switch and start a new reading sequence. A strict read is never upgraded automatically and an old continuation cursor is never carried over. / **跟随更新必须明确请求。** `contextRef` 用于绑定服务快照和解析短句柄；省略它本身不表示允许返回新版。对持久引用的普通读取保持严格核验，无论是否带 context。只有明确请求跟随更新才可以进入新版本，并且必须报告版本切换、开始新的读取序列。严格读取不得被自动升级，旧续读游标不得沿用。
- **How the request is expressed** (confirmed by the owner on 2026-11-13): a single explicit option on `read`, not a second meaning for `open`, which is the browser handoff with its own verification fields. The option name and response fields are fixed in the Round 2 reference design. No new reference prefix and no per-query identity is required. / **请求如何表达**（负责人已于 2026-11-13 确认）：用 `read` 上的单一显式选项，不给 `open` 增加第二层含义，后者是交给浏览器的入口，有自己的核验字段。选项名与响应字段在第二轮引用设计时确定。不需要新增引用前缀，也不需要为每次查询另建身份。
- **Reference formats are unambiguously distinguishable.** Keeping the `er2` prefix is allowed, but a format discriminator is required before new meanings can be assigned to fields used by legacy `er2`; legacy references keep their original interpretation. Unknown formats are rejected explicitly. / **引用格式须能无歧义区分。** 可以沿用 `er2` 前缀，但为旧 `er2` 所用字段赋予新含义之前，必须有格式判别；旧引用保持原有解释。未知格式明确拒绝。
- **What a strict read offers is a new-version read request, not a continuation.** It can be submitted as given and starts a new reading sequence: it is never placed in the `nextCursor` of the old paging and never reuses the old short handle, context, offset or an invalidated hit position. It uses a verifiable durable event identity; parts, budgets and similar parameters are kept only where their meaning is unchanged, and it says so when the original hit cannot be relocated reliably. / **严格读取提供的是新版本读取请求，不是续读。** 它可直接提交并开始新的读取序列：不放进旧分页的 `nextCursor`，不沿用旧短句柄、旧 context、旧偏移或已失效的命中位置。它使用可核验的持久事件身份；parts、预算等参数仅在含义不变时保留，原命中无法可靠重定位时须明确说明。
- **Three cases for a strict read.** The old version can still be verified: return the old version, optionally with the new-version request. The old version cannot be verified but a new version of the same event is confirmed: report the old version as unavailable and give the explicit request. Event identity or change state cannot be confirmed reliably: stay with "cannot determine" or a resolution error; a changed Session digest alone never shows that this event was updated. / **严格读取的三种情形。** 旧版仍可核验：返回旧版，可另附新版本读取请求。旧版不可核验但已确认同一事件存在新版：明确报告旧版不可用，并给出显式请求。事件身份或变化状态无法可靠确认：保留"无法判断"或解析错误；仅凭会话摘要变化不得声称该事件已更新。
- **The option selects among available event versions.** Whether a new index is built or published stays with the lifecycle mechanism, so a read option never takes on refresh or a long index build. / **该选项只在可用的事件版本中选择。** 是否构建或发布新索引仍由生命周期机制负责，读取选项不承担刷新或长时间的索引构建。
- **The Viewer is a consumer of the same rules.** It resolves evidence links with the reference alone; for an updated version it stays strict and tells the reader, and never shows a new body under the old link silently. / **Viewer 是同一套规则的使用方。** 它仅凭引用解析证据链接；遇到已更新版本时保持严格并告知读者，不得在旧链接下悄悄显示新正文。
- **Scope includes the normalized path policy identity.** The project path interpretation and the normalized policy identity are part of scope for references and for any cache that depends on the policy. Rules are normalized, deduplicated and sorted before the digest, so a change in file layout, rule order or an equivalent spelling does not invalidate references; a real change of identity is a different scope even when source bytes and the Session set happen to agree. A reference minted under another identity resolves only through an alias for a proven-compatible case, as `4da2188` does for the default unambiguous interpretation. This is decided at scope verification: it is not the event state "updated" and the follow option cannot bypass it. / **范围包含规范化后的路径策略身份。** 项目路径解释与规范化后的策略身份属于引用范围，也属于依赖该策略的缓存的键。规则在生成摘要前经过规范化、去重与排序，因此配置文件排版、规则顺序或等价路径写法的变化不使引用失效；真正的身份变化即使来源字节与会话集合碰巧一致，也构成不同范围。在另一身份下生成的引用，只能经已证明兼容情形的别名解析，如 `4da2188` 对默认且无歧义解释的处理。此事在范围核验阶段处理：它不属于事件状态"已更新"，也不能被跟新选项绕过。
- **Version comparison is three-state, only after scope and event identity are verified:** same version, updated version, or cannot determine. Scope mismatch, a vanished event, ambiguous identity or incompatible interpretation remain resolution errors; no target is guessed from similar text or an old ordinal. A legacy `er2` has no event-level version basis, so a changed Session digest alone yields "cannot determine". / **版本比较为三态，且仅在范围与事件身份已核验之后：** 版本一致、已更新、无法判断。范围不符、事件消失、身份歧义或解释不兼容仍是解析错误，不凭相似文本或旧序号猜目标。旧 `er2` 没有事件级版本依据，仅凭会话摘要变化只能得出"无法判断"。
- A response that returns an updated version carries the requested reference, the reference of the body actually returned, the comparison state, and whether the old version can still be verified, in both `full` and `compact`. The returned body is never left under the old evidence reference. / 返回更新版本的响应须同时带原请求引用、实际返回正文的引用、比较状态及旧版本是否仍可核验，`full` 与 `compact` 都保留。返回的新正文不得仍挂在旧证据引用之下。
- A stored hit offset belongs to one projection version. When the projection changes it is invalidated, and recomputed only from a reliable anchor or the original query with the match reverified. / 已存命中偏移属于某一投影版本；投影变化即失效，仅在有可靠锚点或原查询并重新核验匹配时重算。
- The first persisted cache rejects an unknown format or parser version and rebuilds. It does not promise permanent retention of original content; a query-projection cache is not an evidence archive, and cached search text is never presented as original evidence after a source is deleted. / 第一版持久缓存遇到不认识的格式或解析器版本即拒绝加载并重建。它不承诺永久保存原始内容；查询投影缓存不是证据归档，来源删除后不得以缓存的搜索文本冒充原始证据。

## Later architecture work / 后续架构工作

- **Automatic refresh.** Queries keep a version boundary so a first page, a second page and a later read never straddle different history states. Today a context, a service instance and a snapshot are the same thing because a service indexes once; refresh separates them, and Round 2 reference rules must not rely on their being equal. Recommended by both reviewers: a new context is assigned when a new snapshot is published successfully. The old context stays bound to the old snapshot within a stated retention period or resource limit; when it expires it fails explicitly and is never redirected to the new snapshot. A check that finds no change and a failed build do not switch. This is a lifecycle rule of the refresh work; the full multi-snapshot retention mechanism is not pulled into Round 2. Once `status` or the refresh result reports the index version and cutoff, last check and update times, pending updates, and failed or unchecked sources, the standalone `observe` command can be withdrawn or reduced to diagnostics. / **自动刷新。** 查询保留版本边界，使第一页、第二页与随后读取不落在不同历史状态。目前 context、服务实例与快照是同一个东西，因为服务只索引一次；刷新会把三者分开，第二轮的引用规则不得依赖三者相等。两位评审者共同建议：新快照成功发布后分配新的 context。旧 context 在明确的保留期限或资源上限内继续绑定旧快照；过期时明确失败，不转向新快照。无变化的检查和失败的构建不触发切换。这是刷新工作的生命周期规则，完整的多快照保留机制不提前放进第二轮。当 `status` 或刷新结果能报告索引版本与截止时间、最近检查与更新时间、未纳入的更新、失败或未检查的来源后，可取消独立 `observe` 命令或降为诊断功能。
- **Process hosting.** Automatic attach, harness-hosted processes or a thin stdio MCP adapter are scheduled by what the no-service condition shows, and may move earlier. ## Independent search optimisation / 独立搜索优化

An inverted index narrows candidates while the existing literal matcher confirms matches and locates hit offsets. Short terms keep a scan fallback: with the FTS5 trigram tokenizer, a full-text query for a substring shorter than three Unicode characters matches nothing, which covers common two-character Chinese words and identifiers such as `CI`. Relevance ranking is evaluated on its own; event-type weights are not fixed, since tool output is the direct evidence for some questions. / 倒排索引缩小候选，现有字面 matcher 负责确认匹配与定位命中偏移。短词保留扫描回退：使用 FTS5 trigram tokenizer 时，全文查询中少于三个 Unicode 字符的子串不会命中，这涉及常见的中文双字词及 `CI` 一类标识。相关性排序单独评估；不固定事件类型权重，因为某些问题的直接证据正是工具输出。

A later presentation experiment may compare line-oriented text with compact JSON. It fixes the backend, event set, order, read ranges and required evidence fields, and covers long tool output with continuation, cross-Session rules with later reversals, missing sources and partial coverage, and handoff of a verifiable reference. An output that saves bytes by dropping coverage or continuation information does not win at equal quality. / 之后的呈现实验可比较行式文本与紧凑 JSON。实验固定后端、事件集合、顺序、读取范围与必要证据字段，并覆盖带续读的长工具输出、跨会话规则与后续推翻、来源缺失与部分覆盖，以及可核验引用的交付。靠丢掉覆盖或续读信息节省字节的输出，不算同等质量下胜出。
