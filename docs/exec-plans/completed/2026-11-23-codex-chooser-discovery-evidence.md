# Codex chooser discovery evidence / Codex 项目选择器发现依据

Base `0023858` plus the existing local chooser change. The desired behavior is to hide a redundant list entry only with sufficient evidence, make it selectable again when that evidence fails, and preserve the original project key. / 基线为 `0023858` 及现有本地选择器变更。目标是仅在依据充分时隐藏重复入口、依据失效时恢复可选择性，并保留原项目 key。

## Decisions / 决策

- Use the same decoded `cwd` membership in discovery and indexing. Ordinary scans can skip lines that cannot contain a literal or escaped `cwd` key. Only a native Windows Codex full scan with an eligible configured extended drive root needs to check every record for uncertainty in the existing bounded, cancellable scan. Valid metadata without `cwd` contributes no recorded association. Explicit malformed values and undecodable records make coverage incomplete while readable evidence still contributes. / 发现与索引使用一致的解码 `cwd` 归属。普通扫描可以跳过没有字面或转义 cwd key 的行。仅当 Windows 原生服务的 Codex 完整扫描遇到符合条件的扩展盘符配置根时，才在现有有界、可取消的扫描中检查每条记录是否带来不确定性。合法元数据缺少 cwd 时不贡献记录归属。显式损坏的值或无法解码的记录使覆盖不完整，可读依据继续参与。
- Suppress a configured row only when the latest completed scan supports it. Require an ordinary transcript candidate, matching native directory identities, and no extended project membership at the same root or any descendant. Use fresh configuration spellings when reusing cached statistics. A failed full scan revokes the cached negative evidence unless a newer scan has already replaced it or the request was abandoned. Coverage describes the observed artifacts in that scan. / 仅在最近一次完整扫描提供依据时隐藏配置项。要求存在普通路径的转录候选、本机目录身份一致、且扩展根及子目录都无记录归属。复用缓存统计时以当前配置拼写为准。完整扫描失败会撤销此前的缓存负向依据，更新的扫描已替换缓存或请求已放弃时例外。覆盖只描述该次扫描观察到的工件。
- The browser retains the last accepted chooser result for the same source and path policy. A current discovery failure makes previously hidden choices selectable with unverified activity until a successful full scan applies a new result. Obsolete requests and source conflicts cannot replay old rows. Automatic restoration still uses accepted full discovery and checks the saved key, source and policy. / 浏览器保留同一来源和路径策略下最近接受的选择器结果。当前发现失败后，之前隐藏的入口恢复可选，活动标为未核实，直到成功的完整扫描应用新结果。过期请求和来源冲突不能重放旧条目。自动恢复继续依据已接受的完整发现结果，并核对保存的 key、来源和策略。
- A configuration read error retains known same-scope choices as unverified. A successful read or an absent file establishes which configured keys still exist. The browser waits for verification before automatically restoring a configuration-only saved choice. / 配置读取失败时保留同范围下已知的入口，标为未核实。成功读取配置或确认文件缺失时，据此确定哪些配置 key 仍存在。纯配置入口自动恢复前，浏览器会等待核实。
