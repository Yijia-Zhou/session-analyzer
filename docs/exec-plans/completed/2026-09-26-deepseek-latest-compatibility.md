## Baseline gaps (resolved by this implementation) / 基线缺口（本次实现已修复）

1. **Discovery and generation selection.** `src/deepseek-harness.js` only recognizes `session.jsonl` and `session.jsonl.zstd`. Upstream now preserves immutable generations named `session.vN.jsonl[.zstd]`. A synthetic v4-only directory produces zero Sessions and zero diagnostics; coexisting v0/v4 produces one v0 Session and zero diagnostics. A successor must not cause silent predecessor selection or duplicate indexing. / **发现与代际选择。** 当前只识别旧文件名；新版保存不可变版本工件。合成探针复现新版文件静默遗漏及并存时读取旧代的问题，适配应明确代际选择、去重和不支持版本诊断。
2. **Header and physical format.** `src/deepseek-harness-storage.js` supports format 0 and rejects a v4 header with `DEEPSEEK_FORMAT_VERSION_UNSUPPORTED`. Newer headers use `isSeeded`; v2+ derives inherited ownership from tagged `session/end-seed` and uses new source-reference encoding. Increasing the version ceiling alone is insufficient. / **Header 与物理格式。** 当前只支持 format 0，v4 header 被明确拒绝；新版 header、继承边界与引用编码需要独立解码，不能只提高版本上限。
3. **Assistant streams and attempts.** V2 embeds timed streams in `assistant/message`, uses `assistant/attempt` for attempts without a committed surface message, and removes top-level `assistant/chunk`. Partial output, retries, reasoning, timestamps and Raw locators need version-specific handling. / **Assistant 流与尝试。** V2 将时间流嵌入 message，并用 attempt 保留未提交表面消息的尝试；部分输出、重试、推理、时间和 Raw 定位均需按版本处理。
4. **PTC and surface semantics.** `tool/code-dispatch[-start]` becomes `tool/ptc-dispatch[-start]`; v3 changes surface references and system-message representation; v4 introduces tool-role result messages and changes producer-source vocabulary. Audit exact shapes before reusing existing Code Mode, tool-result, inbox and prune projection. / **PTC 与表面语义。** 事件名、system message、surface 引用、tool-role result 和来源词汇均有变化，应先核对精确结构再复用现有投影。
5. **Vocabulary and relationships.** The adapter knows 48 event types; the tagged upstream knows 59 (14 additions, 3 removals). Additions include system/developer messages, assistant attempts, model selection, subagent catalog/policy, workspace changes, deliverables, image offload and feedback edits. Approval endpoint payloads and four outcomes remain structurally unchanged in the inspected declarations; envelope and call-reference compatibility still require tests. / **事件词汇与关系。** 新增及移除清单已记录；审批端点声明结构未变，但不能据此跳过新版 envelope 与调用引用验证。
