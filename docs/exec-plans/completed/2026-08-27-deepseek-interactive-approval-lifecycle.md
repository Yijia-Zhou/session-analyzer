## Delivered invariants / 已交付不变量

1. Pair only by exact non-empty request ID; a recoverable malformed counterpart poisons the whole child-owned request group. Exact current-v0 endpoint keys and outcome vocabulary fail closed on any extra or malformed field. / 只按精确非空 request ID 配对；带可恢复 ID 的畸形 counterpart 会使整个 child-owned request group 保守失败。Current-v0 端点 key 与 outcome 词汇精确校验，任何多余或畸形 field 都会 fail closed。
2. Asked-only evidence is valid normal-severity `incomplete`, owns only asked Raw, and never implies a live wait. Complete evidence owns only asked/decided Raw and preserves the exact outcome with neutral `recorded` status; only `unavailable` has warning severity. / Asked-only evidence 是 normal severity 的有效 `incomplete`，只拥有 asked Raw，且绝不暗示当前仍在等待；完整 evidence 只拥有 asked／decided Raw，以 neutral `recorded` status 保留精确 outcome；只有 `unavailable` 使用 warning severity。
3. Both endpoints require parse-time open-turn context without a same-turn or adjacency requirement. Parent/child seed crossings never pair. / 两个端点都要求 parse-time open-turn context，但不要求同一 turn 或相邻；parent／child seed crossing 绝不配对。
4. Optional exact `callId` is a relation fact only. `toolRef` is emitted only for one existing unique child-owned tool Logical Event in the same seed boundary; absent, unresolved, ambiguous, or cross-seed targets omit it without suppression diagnostics. / 可选精确 `callId` 只属于 relation fact；只有同一 seed boundary 中存在唯一 child-owned 工具 Logical Event 时才生成 `toolRef`；target 缺失、未解析、有歧义或跨 seed 时省略该字段，且不持久化 suppression diagnostic。
5. Permission state stays independent; no denial-to-retry provenance, Raw transfer, duplicate generic endpoint, Main effect, canonical field, or browser branch is introduced. / Permission state 保持独立；不引入 denial 到 retry provenance、Raw 转移、重复 generic endpoint、Main 影响、canonical field 或 browser branch。
