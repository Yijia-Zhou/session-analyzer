# v0.1.3 review follow-ups / v0.1.3 评审后续修复

## Objective / 目标

Close the confirmed Claude Code adapter and shared logical-detail findings before the `0.1.3` release candidate is accepted: preserve fail-closed subagent correlation, keep thinking signatures Raw-only, retain ordinary prose after embedded base64 data URLs, separate canonical unknown-tool labels from source-owned names, and restore scalar Raw titles. / 在接受 `0.1.3` 发布候选之前，完成已确认的 Claude Code 适配器与共享逻辑详情问题修复：保持 subagent 关联 fail closed、让 thinking signature 仅保留在 Raw、保留内嵌 base64 data URL 后的普通正文、分离未知工具的 canonical label 与来源拥有名称，并恢复标量 Raw 标题。

## Scope / 范围

1. Require one unique parent Agent result by `agentId` before validating an optional sidecar `toolUseId`. / 在校验可选 sidecar `toolUseId` 前，先要求按 `agentId` 得到唯一父 Agent result。
2. Exclude exact `signature` fields from ordinary Logical detail while retaining them in Raw detail and indexed Raw readback. / 从普通 Logical detail 中排除精确的 `signature` 字段，同时在 Raw detail 与索引 Raw 回读中保留。
3. Stop embedded base64 redaction at an ordinary prose boundary without exposing structurally valid wrapped payloads, including lowercase-only chunks, or malformed payload continuations. / 在普通正文边界停止内嵌 base64 脱敏，同时不暴露结构合法的换行包装 payload（包括全小写 chunk）或畸形 payload continuation。
4. Use the canonical `Other tool call` label for unknown Claude tools while retaining the exact source name in `toolName`, `subtype`, and search text. / 对未知 Claude 工具使用 canonical `Other tool call` label，同时在 `toolName`、`subtype` 与搜索文本中保留精确来源名称。
5. Build Claude Raw titles from `payloadType || recordType` rather than the Raw object. / 使用 `payloadType || recordType` 而不是 Raw 对象构造 Claude Raw 标题。
6. Re-render the timeline synchronously when switching from inherited pointer-fork context to its parent so child-owned DOM cannot remain under the parent header while requests are pending. / 从继承 pointer-fork 上下文切换到父会话时同步重绘时间线，避免请求等待期间 child-owned DOM 残留在父会话标题下。
