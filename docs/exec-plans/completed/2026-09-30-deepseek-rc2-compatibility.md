## Evidence and decision / 证据与决策

The five core Session/event/message/stream/PTC files have identical Git blobs across 0.1.7-rc.2, 0.2.0-rc.1, and 0.2.0-rc.2. However, `packages/interaction/user-questions/src/types.ts` extends `MessageSourceMap` with `user-question-reply`; its answer RPC steers a normal user message with exact `callId` and `outcome: answered`. The persistence note declares `same-version`, no new event type/header, and format 4 remains unchanged. / Session／event／message／stream／PTC 五个核心文件在三个版本间 Git blob 相同，但问答类型声明扩展了 `MessageSourceMap`；answer RPC 以精确调用 ID 和回答结果提交普通用户消息。持久化说明声明同版本兼容，不新增事件类型或 header，仍为 format 4。

Analyzer currently checks only `source.kind === 'user'` in Raw normalization and Main mapping; qualified replies fall into Protocol, miss user counts, and have no qualified Main Detail evidence. Add a bounded source classifier shared by both paths, accepting only source-authorized human input (`user`, `user-question-reply`). Keep append-only promotion and runtime-source fallback. Reuse existing Detail `kv` traceability sections; retain original source identifiers and Raw ownership. / Analyzer 的 Raw 规范化与 Main 映射目前只检查 user，导致限定来源的回复进入 Protocol、漏计用户消息且缺少 Main 详情来源证据。两条路径共用小型分类函数，只接纳上游证明的人类输入来源；保留 append 晋升边界和运行时来源回退。复用详情键值追溯区块，保留原始来源标识和 Raw 归属。
