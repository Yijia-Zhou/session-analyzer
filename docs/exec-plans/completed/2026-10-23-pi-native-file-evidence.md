## Outcome and scope / 目标与范围

The [completed maturation increment](../completed/2026-10-23-pi-reader-maturation.md) already implements the original coverage/branch/statistics and native-tool batch. This follow-up makes the matrix describe current support and closes demonstrated native-file evidence gaps; it does not repeat that implementation or silently broaden compatibility. / 已完成的完善增量已经实现原计划中的覆盖、分支／统计及原生工具首批能力。本轮将矩阵更新为当前支持状况，并关闭已证实的原生文件依据缺口，不重复实现或静默扩大兼容范围。

1. Consolidate the [coverage matrix](../../design-docs/pi-protocol-event-coverage.md), with current status, exact fixture links and explicit deferred work. Freeze branch path counts, physical artifact sizes, file activity versus confirmed edit counts and partial usage categories. / 整理覆盖矩阵，列明当前状态、精确 fixture 链接及延后工作；明确分支路径计数、物理工件大小、文件活动与已确认修改计数、部分类别用量。
2. Require coherent old/new hunk coordinates and valid EOF markers before admitting native result patches. Keep valid zero ranges, shifted hunks and newline-only changes. / 原生结果 patch 准入要求新旧 hunk 坐标一致及有效 EOF 标记；保留有效零行范围、偏移 hunk 与仅换行变化。
3. Admit the pinned native optional-directory default (`path` omitted or empty) for grep/find/ls, without invented file association. / 接纳固定版本 grep／find／ls 的可选目录默认值（省略或空路径），不补造文件归属。
4. Verify a shared read/write/edit prefix with successful, failed, incomplete and contradictory edit branches through indexing, materialization, search, file activity, counts and exact Raw. Exercise the same file-change boundary in desktop/mobile and both UI locales. / 对共享读写修改前缀及成功、失败、未完成、矛盾修改分支，联合验证索引、物化、搜索、文件活动、计数及精确 Raw；在桌面／移动端及双语浏览器验证相同修改边界。

## Evidence and decisions / 依据与决策

- Pinned `@earendil-works/pi-coding-agent@1.4.0` session v3, `dist/core/tools/edit.js`, and its `diff@8.0.4` dependency define the producer: `createTwoFilesPatch` with context 4 and `FILE_HEADERS_ONLY`. Golden patches are synthetic and committed as strings; no dependency was added. / 以固定 pi 1.4.0、session v3、edit.js 及其 diff 8.0.4 依赖确定生产器及选项；golden patch 为合成字符串，不新增依赖。
- Old admission accepted `@@ -1 +100 @@` despite contradictory unchanged-prefix lengths and accepted misplaced EOF markers. This incorrectly created patch/file statistics. Source success and patch validity are separate facts: rejected patches remain successful tool receipts when so recorded, with request activity and complete Raw. / 旧准入接纳前缀长度矛盾的所列 hunk 及错误 EOF 标记，误生成 patch／文件统计。来源成功与 patch 有效性是独立事实；被拒绝的 patch 仍按记录保留成功工具回执、请求活动及完整 Raw。
- Pinned `grep.js`, `find.js`, `ls.js` execute with `path || '.'`. Omitted/empty paths are supported native requests; null/object paths retain generic fallback. Required read/write/edit paths remain unchanged. / 固定版本所列三项工具以 path 或默认目录执行；省略／空路径属于支持的原生请求，null／对象保留通用回退；read／write／edit 必填路径规则不变。
- Durable bookmarks, native-session deduplicated totals, full context replay, media and extension-specific presentation remain separate [follow-ups](../tech-debt-tracker.md). No model calls, credentials, transcript changes or recorded-tool execution are needed. / 持久书签、去重原生会话总量、完整上下文重放、媒体及扩展专用展示仍为独立后续；本轮无需模型调用、凭据、转录修改或执行历史工具。
