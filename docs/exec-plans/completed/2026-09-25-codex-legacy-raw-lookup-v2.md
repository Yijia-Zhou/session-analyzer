The figures below are single synthetic runs on Windows/Node 24.18.1; work bytes are explicit proxies, RSS is sampled process memory, and retained heap is the post-GC delta. They are not process memory limits or real-corpus guarantees. / 每个场景单独执行一次 `node --expose-gc scripts/legacy-raw-owner-profile.js <scenario>`。下列数字是 Windows／Node 24.18.1 的单次合成运行；工作字节是明确的代理计量值，RSS 为采样的进程内存，retained heap 是 GC 后差值。它们不是进程内存上限，也不代表真实语料保证。
