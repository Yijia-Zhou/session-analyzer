## Findings and implementation / 发现与实现

The [pinned compatibility design](../../design-docs/deepseek-format4-compatibility.md#deepseek-021rc2) records the source matrix. Storage format/header/envelope, message/assistant-stream and shell status renderers remain compatible. Optional user principals, external catalogs, and experimental plugin records retain established classification/fallback. Working-directory changes affect later operations, while the immutable header still identifies the original project. / 所链固定版本兼容设计记录来源矩阵。存储格式／header／envelope、消息／assistant 流及 shell 状态 renderer 保持兼容。可选用户 principal、外部 catalog 与实验性插件记录沿用既有分类／回退；工作目录变更影响后续操作，不可变 header 仍标识初始项目。

Two demonstrated gaps were repaired: / 修复两处已证实缺口：

1. `job/registered`, `job/settled`, and `working-directory/change` previously became warning `unknown_event`. Add only the official event names to the known set; they remain normal Protocol, without job/tool lifecycle inference. / 三个正式事件原先被误报未知事件警告；仅补入已知集合，作为正常 Protocol，不推断 job／工具生命周期。
2. Direct/PTC operation metadata was only visible in Raw. Detail now shows recorded shell cwd/file target under unique ownership, with bilingual keys and bounded fallback for remaining metadata. No canonical field, navigation identity, project association or count/query behavior changes. / 直接／PTC 操作元数据原先仅 Raw 可见；现在在归属唯一时展示已记录 shell 目录／文件目标，字段双语，剩余元数据有界回退。不改变 canonical 字段、导航身份、项目归属或计数／查询行为。
