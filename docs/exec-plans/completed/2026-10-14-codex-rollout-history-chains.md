# Codex rollout history chains / Codex rollout 历史链

Status: completed; implementation, automated validation and real-project acceptance passed. / 状态：完成；实现、自动验证及真实项目验收通过。

## Problem and scope / 问题与范围

Codex `thread/revert` can create several physical rollout artifacts for one stable logical Session. The current reader admits duplicate Session IDs and source-backed indexing rejects them. Resolve explicit history chains without inventing Session identities, merging superseded tails into current history, or changing original artifacts. Implement with GPT-6.1 Sol and parent review. / Codex 的 thread/revert 可为同一逻辑会话创建多份物理 rollout。当前 reader 接纳重复会话 ID，来源支持索引随即拒绝。需解析显式历史链，不能虚构会话身份、将被回退尾部并入当前历史或修改原始工件。由 GPT-6.1 Sol 实现、主 agent 审查。

## Source evidence / 来源依据

- Pinned [recorder](https://github.com/openai/codex/blob/rust-v0.162.1/codex-rs/rollout/src/recorder.rs): revert preserves thread identity and creates an immutable `<conversation_id>_<rollout_id>` artifact. / 固定版本 recorder：回退保留线程身份，创建带独立 rollout ID 的不可变工件。
- Pinned [protocol](https://github.com/openai/codex/blob/rust-v0.162.1/codex-rs/protocol/src/protocol.rs): `history_base.thread_id` means physical RolloutId, while `session_meta.id` remains stable. The base specifies exclusive ordinal and byte boundaries; logical fork boundaries are independent. / 固定版本 protocol：history_base.thread_id 表示物理 RolloutId，session_meta.id 保持稳定；基底指定序号与字节的排他边界，逻辑分叉边界独立。
- A minimized synthetic duplicate-ID case fails with both baseline HEAD dependencies and the first-round tree. Real metadata shows a three-artifact chain; real transcript content is not a fixture. / 最小合成重复 ID 案例在基线 HEAD 依赖与首轮工作树均失败；真实 metadata 显示三工件链，真实转录正文不作为 fixture。

## Implementation boundaries / 实现边界

Resolve authoritative segment selection before logical event construction. Preserve physical file/line source locators, exact Raw reads, stable identities, dependency validation and cross-source contracts. Determine upstream ordinal counting, metadata selection and active-head evidence before coding these decisions. Missing, cyclic, contradictory or ambiguous chains must produce explicit diagnostics, never a claimed complete history. / 在逻辑事件构建前确定有依据的分段选择。保留物理文件／行定位、精确 Raw 回读、稳定身份、依赖校验和跨来源契约。编码前确认上游序号计数、metadata 选择及当前文件依据。缺失、循环、矛盾或歧义链必须产生明确诊断，不能声称完整历史。
