## Contracts and remaining boundaries / 合同与剩余边界

- Public canonical schema stays at version 1. Plain dependency identities remain compatible; compressed identities add the `compression: zstd` discriminator. Raw locators use logical `.jsonl` names and decompressed lines. Rebuild/restart the in-memory index to apply new semantics; there is no persisted transcript migration or source rewrite. / 公开 canonical schema 保持版本 1。普通依赖 identity 保持兼容；压缩 identity 增加 compression: zstd 区分项。Raw locator 使用逻辑 .jsonl 名称和解压行号。重建／重启内存索引以应用新语义；无持久化转录迁移或来源改写。
- Main/Search/Detail gain only the admitted external/async/attachment facts; Raw remains authoritative. Tool/user counts are unchanged by external inputs and attachments. Unknown canonical items, including external-output mirrors and non-async canonical AgentMessage, retain Protocol/Raw rather than speculative admission. / Main／Search／Detail 仅新增准入的外部／异步／附件事实，Raw 继续具有来源权威性。外部输入与附件不改变工具／用户统计。未知 canonical item（含外部输出镜像、非 async canonical AgentMessage）保持 Protocol／Raw，不推测准入。
- Follow-ups explicitly requested as observation/fixture TODOs remain in debt #26: further paginated items, retained/sender context, URI roots and runtime-only candidates. No real recent-format corpus survey was performed; synthetic evidence does not assert default rollout availability. / 交接明确列为观察／fixture 待办的方向保留于债务 #26：更多分页 item、retained／sender context、URI roots 和 runtime-only 候选。未进行真实近期格式语料普查；合成依据不代表默认 rollout 可用性。
