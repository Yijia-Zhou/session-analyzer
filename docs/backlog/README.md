# Backlog

This directory stores rough, uncommitted, long-horizon improvement ideas.
本目录用于存放粗略的、尚未承诺的、远期潜在改进想法。

Items here are not accepted requirements, design decisions, or execution plans.
They are parking-lot notes for future review.
这里的条目不是已接受的需求、设计决策或执行计划，只是供未来复查的暂存笔记。

## When to Use This Area
## 何时使用本区域

Use this area when an idea is plausible but not yet carefully evaluated.
当一个想法看起来可能有价值、但尚未经过仔细评估时，使用本区域暂存。

Do not use it for:
不要把以下内容放入本区域：

- Confirmed product behavior changes.
- 已确认的产品行为变更。
- Architecture decisions that already need tradeoff analysis.
- 已经需要权衡分析的架构决策。
- Work that is ready for near-term execution.
- 已经准备近期执行的工作。
- Known debt that should be tracked as accepted technical debt.
- 应作为已确认技术债跟踪的已知问题。

## Status Values
## 状态值

- `parking`: captured but not evaluated.
- `parking`：已捕获，但尚未评估。
- `watch`: plausible, waiting for more evidence.
- `watch`：看起来可行，等待更多证据。
- `candidate`: worth shaping into a product spec, design doc, or exec plan.
- `candidate`：值得整理成产品规格、设计文档或执行计划。
- `rejected`: intentionally not pursuing now.
- `rejected`：当前明确不推进。
- `promoted`: moved into a product spec, design doc, or exec plan.
- `promoted`：已迁移到产品规格、设计文档或执行计划。

## Promotion Rule
## 晋升规则

Move an item out of backlog only when it has a clear user problem, success
criteria, and an owner or execution window.
只有当条目具备清晰的用户问题、成功标准，以及负责人或执行窗口时，才将其移出 backlog。

## Files
## 文件

- `long-horizon-ideas.md`: default parking lot for remote or under-shaped ideas.
- `long-horizon-ideas.md`：远期或尚未成形想法的默认暂存区。
