## Change and coverage boundary / 修改及覆盖边界

The Codex raw-shard hint now requires both **any supported command-call row in the session** and **any original `session-analyzer` marker anywhere in that session**. It does not require both on the same row or add a `history` literal; escaped command spelling can separate call evidence from the marker. Other sources retain their previous hint. The structured classifier remains the authority for exclusion. / Codex raw 分片提示现在同时要求：**会话内任意受支持命令调用行**，以及**该会话任意位置出现原有 `session-analyzer` 标记**。不要求两者位于同一行，也不新增 `history` 字面词条件；转义后的命令拼写可能使调用依据与标记分离。其它来源保持原提示，结构化分类器仍是排除工件的最终依据。

All seven frozen files lack the currently supported Codex `response_item/function_call` command structure, although other records contain markers. In particular, `custom_tool_call` with tool `exec` appears in this corpus and is outside the current artifact recognizer's supported grammar. Zero recognized artifacts therefore does **not** establish absence of retrieval activity or completeness of protocol coverage. The gate follows that existing coverage boundary; it does not add support for custom tool calls. / 七份冻结文件都缺少当前支持的 Codex `response_item/function_call` 命令结构，尽管其它记录含有标记。尤其是本语料存在工具为 `exec` 的 `custom_tool_call`，它不在当前工件识别器支持的语法内。因此识别数为零**不能**证明没有检索活动或协议覆盖完整；新门槛沿用既有覆盖边界，并未新增 custom tool call 支持。

## Response and freshness checks / 响应及新鲜度检查

All five complete request responses in the final pair pass normalized deep equality. Normalization replaces only service `contextRef`/`coverageRef`, index-build `indexedAt`, and cursor instance context/HMAC. Cursor payloads are decoded first and retain operation, query digest and continuation position; persistent `er2` evidence references remain byte-for-byte equal. All remaining identities, source/session/event information, offsets, content, scan/count/order fields, budgets and continuation semantics remain in the comparison. Startup is measured separately and is not one of these five response comparisons. / 最终配对中五个完整请求响应均通过规范化深度相等检查。规范化仅替换服务 `contextRef`／`coverageRef`、索引构建时间 `indexedAt` 及 cursor 实例上下文／HMAC；cursor 先解码并保留操作、查询摘要及续页位置，持久 `er2` 依据引用逐字节相同。其余身份、source／session／event 信息、偏移、内容、扫描／计数／顺序字段、预算及续页语义均保留在对照中。启动单独量测，不属于这五个响应对照。

This equivalence concerns unchanged frozen sources. When a session has no supported command call, search can now return its committed query projection without an incidental materialization-time stale-source failure. Selected `read`, `context` and `open` still verify evidence strictly and reject rewritten or deleted sources. Error timing for changed sources is consequently not claimed identical. First and repeated reads in the pair each retain full materialization, including source and integrity checks; their cost is not optimized here. / 此相等结论仅针对未改变的冻结来源。会话没有受支持命令调用时，搜索现在可返回已提交查询投影，而不因附带物化而提前触发来源过期错误。选定依据的 `read`、`context`、`open` 仍严格核验，并拒绝改写或删除后的来源；因此不声称来源改变时的错误出现时机完全相同。配对中的首次及重复读取均保留完整物化，包括来源及完整性核验，本轮未优化其成本。

No active full-history sweep, new agent-benefit trial or model-usage measurement was performed. Serialized response sizes are not model usage. The small corpus, single Windows environment, existing protocol coverage gaps and instrumentation limit generalization; direct call counts and response comparison support this specific avoided path. / 本轮未扫描活动全量历史，未新增 agent 收益试验或模型 usage 量测；序列化响应字节不能当作模型 usage。小语料、单一 Windows 环境、既有协议覆盖缺口及插桩限制了推广范围；直接调用计数及响应对照支持的是本次具体被避免的路径。
