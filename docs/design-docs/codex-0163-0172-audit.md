# Codex 0.163–0.172 compatibility audit / 兼容性审计

**2026-11-24 · Investigation and proposals / 调查与提案**

The first implementation increment should fix incorrect message attribution, operation ownership and terminal status. A separate storage increment can recover an otherwise excluded child. Raw evidence survived the message and tool counterexamples; it cannot help a reader select an excluded Session. Navigation, richer detail and task-level token accounting have different acceptance criteria. / 首批适配应纠正消息身份、操作归属与终态；另设存储增量，恢复原本会被排除的子会话。消息和工具反例仍能回查 Raw，被排除的会话则无法进入阅读流程。关系导航、结构化详情和任务级 Token 核算分别验收。

## Coverage matrix / 覆盖矩阵

**Durable envelope inventory.** At the baseline, `codex-rs/history/src/lib.rs:212,362` defines the top-level items and physical line. At the candidate, lines 415–440 and 628 onward retain this envelope; `DynamicToolsUpdated` is the added family, while boxing SessionMeta/Compacted changes Rust representation. `rollout/src/policy.rs:23–50,130–159,184–228,236–285` separately admits response items, mode-dependent lifecycle/typed items and Paginated realtime items. It drops `PrivateSessionEvent`, `ElicitationAbandoned` and `NetworkApprovalResolved`. Seeing a new notification or an App Server search result does not establish a new history row. / 对比顶层枚举、物理行与准入策略后，可确认新增动态工具目录；SessionMeta/Compacted 装箱属于 Rust 表示变化。新增私有订阅、elicitation 放弃和网络审批解决通知受策略过滤。

**Replay-only and compatibility fields.** Candidate `history/src/lib.rs:89–176,205–210`, `core/src/session/turn_input.rs:1205`, `core/src/compact_retained_tool_outputs.rs:10`, `core/src/image_preparation.rs:440–486` and `core/src/model_search.rs:154–174,218–221` show different uses of the optional envelope metadata. Per-item retention can override legacy `client_authored`, replay sources can carry original image data, and model-search state helps restore tools. `producer_bounded_tool_audio` is serde-skipped. Preserve decodable original records, avoid indexing large original image bytes as new user actions, and benchmark a real failing case before revising limits. / 保留范围、图像重放材料与上游模型搜索状态属于各自的恢复路径；部分 Rust 标志根本不序列化。这些字段未证明新用户操作或容量回归。

**Permission snapshots.** Commit `2889d8e1bf` makes the turn's internal permission profile required. `protocol/src/protocol.rs:3722–3744,3764–3827` still accepts legacy policy on read; `history/src/rollout_payload.rs:83–112` emits the legacy sandbox policy and conditional file-system policy. Analyzer 2B projects selected model/effort facts and keeps the original turn context in Raw. Decision: coverage update, with old/new snapshots as controls if permission inspection is proposed later. / Turn 内部权限配置收敛为必填；磁盘兼容字段与旧数据读取路径仍在。现有 2B 取约定模型/effort 事实；权限详情若另行立项须验新旧样本。

## Executed checks and sample limits / 实际验证与样本边界

The main read covered 1,620 physical artifacts, 1,617 distinct primary thread IDs and 917,036 records. It decoded 5,272,155,378 bytes from 1,399,217,687 bytes on disk. All first headers indicated Paginated history. Seven first headers had version 0.172.0. Five files changed during the bounded scan and 29 nested array walks reached their 128-element cap. No physical line exceeded the 32 MiB scan limit. A first header dates an artifact and cannot identify every appended record's producer. / 主扫描逐行读完库存前缀，首条元数据全部为 Paginated，Legacy 另用真实 writer 做对照。文件、逻辑会话、记录与用户数的分母不同。语料的功能频率不作外推。[Inventory, limits and aggregate](../research/codex-0172/corpus.md)

At the pinned Analyzer SHA, 170 storage/lineage/capacity tests, 89 operations/cache/configuration tests and 48 message tests passed (307 focused Node tests). Two existing Chromium controls also passed in a separate checkout built from that SHA: single-tool Code Mode and Trajectory search expansion. The opt-in probes additionally exercised real History CLI search/read, physical Raw lookups and cold/reused materialization. The relationship writer used the native 0.172.0 executable and a loopback provider. These tests do not measure new-feature DOM behavior, production billing, full CI or upstream Rust test results. / 在固定基线运行 307 项聚焦 Node 测试与 2 项既有 Chromium 用例。专项探针另验 CLI、Raw、物化与本地 writer。新形态逐项浏览器交互、生产计费、完整 CI 和上游 Rust 测试仍未验证。独立复核重跑的重叠测试不重复计入。
