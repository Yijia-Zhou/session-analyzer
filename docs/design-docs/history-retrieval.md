# History retrieval design / 历史检索设计

Status: accepted implementation direction, 2026-09-23. / 状态：已接受实现方向，2026-09-23。

## Snapshot-bound viewer / 绑定快照的查看入口

`history open` is an explicit orchestration operation. The service reuses compact-handle, scope, snapshot and event resolution; it requires a single event and materializes the selected source to verify accepted bytes. It preserves the projection hit offset in the exported evidenceRef and obtains a bounded excerpt and existing context window. Only after validation does the history transport start one lazy Web listener; concurrent opens share startup. Browser launch belongs to the CLI. / history open 是显式编排操作，服务复用短句柄、范围、快照和事件解析，要求单事件并物化选定来源以核验已接受字节；导出的 evidenceRef 保留投影命中偏移，获取有界摘录及既有 context 窗口。核验成功后检索传输层才启动按需 Web listener，并发打开共享启动过程。浏览器启动归 CLI。

The viewer reuses `createServer(initialIndex)` with an explicit borrowed, fixed-scope mode and no `repo` startup option; no second index is built. Web revision leases own request cancellation and materialization cache, while history owns the shared ProjectQueryStore. Viewer shutdown retires its lease without disposing query storage; history shutdown closes the viewer before final disposal. Prewarming is disabled. / 查看页以明确的借用、固定范围模式复用 createServer(initialIndex)，不传会触发索引的 repo 选项，不建立第二份索引。Web revision lease 管理请求取消与物化缓存，history 拥有共享 ProjectQueryStore。查看服务关闭时退役 lease 但不释放查询存储；history 关闭时先关闭查看服务再最终释放。禁用预热。

The history listener retains its non-browser boundary. The viewer binds `127.0.0.1`, verifies exact Host, rejects foreign Origin and cross-site data requests, emits no permissive CORS, and sets `Referrer-Policy: no-referrer`. Fixed-scope guards reject source/project mutations and project discovery before normal dispatch. `/api/state` declares `historyViewer.fixedScope` for browser controls. `/api/history/resolve?ref=...` independently revalidates page startup/refresh; the outer URL carries the durable reference in its fragment. / 检索 listener 保持非浏览器边界。查看服务绑定回环地址，核验准确 Host，拒绝外部 Origin 与跨站数据请求，不开放宽松 CORS，设置禁止发送 Referer。固定范围路由在派发前拒绝来源／项目修改及项目发现；state 能力声明驱动浏览器控件。resolve 端点独立重新核验页面启动／刷新；外部 URL 通过 fragment 携带持久引用。

Landing fetches bounded exact-event summary envelopes into a separate ordered Map, using service-provided context timelineIndex and gap endpoints. Ordinary Timeline cards/details and Inspector are reused; sparse records never enter the canonical prefix or its owner registry. Missing order metadata falls back to the target alone. Local display overrides expand the anchor and summarize neighbors without saving folding preferences. Gap markers use actual endpoint pairs/counts and outward cursors. / 落地将有界的准确事件 summary 封装放入独立有序 Map，使用服务提供的 context timelineIndex 及间隔端点。复用普通 Timeline 卡片／详情及 Inspector；稀疏记录不进入规范前缀及其 owner 注册表。缺少顺序元数据时仅展示目标。临时展示覆盖展开锚点、摘要显示附近记录，不保存折叠偏好。省略标记使用真实端点对／数量及向外游标。

Excerpt mode disables automatic prefix pagination and search preloading. Explicit continuation commits canonical pages in the background without replacing the group DOM, checks operation ownership and every group ID, then renders once. Disclosure and nested-scroll state captured immediately before that render is restored, then the selected record is explicitly located. The first visible excerpt is not a valid continuation anchor because inserted events may separate it from the selected record. Inspector/Raw/closed detail state is retained. Initial and return navigation wait for target detail, recheck request ownership, then locate its header; user input cancels that pending location. Manual navigation, cancellation and newer references invalidate old work. Reading snapshots additionally preserve the reference, local overrides and excerpt viewport; restoration revalidates the reference and required details before consuming the return entry, keeping failures retryable. / 节选模式禁用自动前缀分页及搜索预加载。显式续读在后台提交规范分页，不替换节选组 DOM；核验操作所有权及组内全部 ID 后一次渲染。紧邻该渲染前保存并恢复折叠及内部滚动状态，再显式定位选中记录。首张可见节选不是有效的续读锚点，因为补入事件会拉开它与选中记录的距离。保持 Inspector／Raw／关闭详情状态。初次及返回导航等待目标详情、重新核验请求所有权后定位标题；用户输入取消未完成的定位。手动导航、取消及新引用使旧工作失效。阅读快照额外保存引用、临时覆盖及节选视口；恢复重新核验引用和所需详情后才消耗返回条目，失败保留重试。

Same-session, same-layer event references save the reading snapshot before checking membership in the excerpt Map. Targets inside it keep excerpt mode. For an outside target, retire excerpt mode before the existing event-navigation path captures its destination context and request ownership; its temporary reference card then renders through the ordinary timeline. Do not append outside targets to the sparse excerpt or imply source adjacency. Return revalidates and restores the saved excerpt, while a newer event reference supersedes any held target response. / 同会话、同层事件引用先保存阅读快照，再检查目标是否在摘录 Map 内。组内目标保留摘录模式；组外目标在既有事件导航捕获目标上下文及请求所有权之前退出摘录模式，使临时引用卡片通过普通时间线渲染。不将组外目标追加到稀疏摘录，也不暗示来源顺序相邻。返回重新核验并恢复保存的摘录，后续事件引用则取代被延迟的目标响应。

Button feedback has a separate operation owner because evidence resolution replaces the evidence object. Start the navigation task synchronously, then attach its feedback owner at the first pending boundary. Cancellation retires both; finalization clears only its own feedback. Repeated activation of the same busy control neither restarts nor cancels navigation, while scrolling or other navigation can supersede it. The reusable busyButton pattern reserves indicator space, retains the label and keyboard focus with aria-disabled, and suppresses animation for reduced motion. / 按钮反馈使用独立操作 owner，因为引用解析会替换证据对象。同步启动导航任务，在首个等待边界绑定反馈 owner。取消同时退役二者；结束仅清理自身反馈。同一忙碌控件的重复触发不重启或取消导航，滚动及其他导航仍可取代它。可复用 busyButton 模式预留标记空间，用 aria-disabled 保留文字和键盘焦点，并遵守减少动态效果偏好。

After explicit continuation, only the return action stays in a small sticky footer within the reading pane so a long, growing timeline cannot push it out of reach. The initial excerpt group uses a normal footer, and leaving the reference context removes sticky positioning. / 显式续读后，仅返回操作保留在阅读区的轻量吸底栏中，避免不断加载的长时间线使其难以到达。初始节选组使用普通组后操作区，离开引用上下文后取消吸底。

The CLI validates the loopback URL and exact evidenceRef before invoking a platform opener without shell interpolation. `--no-browser` skips only that invocation. Opener errors preserve target verification and URL readiness and are reported separately. This protocol does not include page receipts or remote browser discovery. / CLI 核验回环 URL 及准确 evidenceRef 后，通过无 shell 插值的平台 opener 打开。no-browser 仅跳过启动调用；opener 失败保留核验与 URL 就绪结果并独立报告。本协议不含页面回执或远端浏览器发现。

Linux uses `gio open <url>`, whose [implementation](https://github.com/GNOME/glib/blob/main/gio/gio-tool-open.c) waits for the asynchronous default-application launch result and then exits, without waiting for the application to close. The CLI still requires launcher exit zero, handles missing launchers and nonzero exits, and bounds a stalled launch at ten seconds. It does not fall back to Linux `xdg-open`: [that launcher's documented behavior](https://manpages.debian.org/testing/xdg-utils/xdg-open.1.en.html) can keep it attached to an already running application, making application lifetime an invalid delivery timeout. The Linux regression fixture isolates MIME associations in temporary XDG directories and keeps its synthetic `.desktop` browser running after receiving the exact URL. / Linux 使用 `gio open <url>`；其实现等待默认应用异步启动结果后退出，不等待应用关闭。CLI 仍要求启动器以零退出，处理启动器缺失及非零退出，并将启动停滞限制为十秒。Linux 不回退到 `xdg-open`：其文档允许启动器持续附着于已启动应用，不能据此用应用运行时长判断请求交付超时。Linux 回归 fixture 在临时 XDG 目录中隔离 MIME 关联，合成 `.desktop` 浏览器收到准确 URL 后继续运行。

See the [open contract](../product-specs/history-retrieval.md#open-evidence-for-a-user--为用户打开证据) and [completed implementation plan](../exec-plans/completed/2026-10-13-history-evidence-open.md). / 参见打开契约与已完成实施计划。

Nearby records render inside the timeline; navigation, progress and errors use a footer after the group. Search excerpts belong to the record's reading surface: after the ordinary content inside the expanded Timeline body. The shared manual-search component follows primary content in selected Trajectory Detail, before supplemental detail and metadata. The shared `search-excerpt` component retains disclosure and scroll state in a bounded, context-keyed map. Coverage runs before full, scoped-owner and suffix highlighting, and on primary disclosure changes; no Timeline mutation observer or scroll-triggered coverage scan is needed. Compare the bounded history hit line literally with readable body text, also accepting ordinary Markdown emphasis/code/list formatting within Markdown sections. The existing markdown-it dependency parses this bounded fragment; link/image destinations, entities and escapes remain literal so hidden metadata cannot establish coverage. Closed, hidden and clipped content, loading previews, interface labels and the supplement itself are excluded; scrollable body text counts. Unproven coverage retains the excerpt and hit preview. Selection keeps the normal renderer and Inspector identity. Return is conditional on leaving the linked record; gap markers describe real omissions. Isolated language changes refresh the same reference with session-list selection suppressed. / 附近记录在时间线内呈现，导航、进度及错误放在组后轻量操作区。搜索摘录归属记录阅读区，放在展开的 Timeline 正文内容之后。共享的手动搜索组件放在所选 Trajectory 主体 Detail 之后、补充详情及元数据之前。共享 search-excerpt 组件用有界、绑定上下文的映射保留展开及滚动状态。在整页、局部 owner、追加后缀高亮之前以及主要内容折叠变化时核对覆盖，无需 Timeline mutation observer 或滚动触发的覆盖扫描。将有界历史命中行与可读正文作字面比较，并允许 Markdown 区段中的普通强调／代码／列表格式。浏览器复用既有 markdown-it 解析有界片段；链接／图片目标、实体和转义保留字面形式，避免将隐藏元数据误算为正文覆盖。排除未展开、隐藏、裁剪内容及加载预览、界面标签和补充片段本身；可滚动正文计入。无法确认时保留摘录及命中预览。选中记录继续使用正常 renderer 及 Inspector 身份。离开链接指向的记录后才显示返回；省略标记仅说明真实省略区间。独立落地切换语言时刷新同一引用，抑制会话列表的自动选择。

Presentation switches use the same owned prefix-loading transition as Continue, leaving the excerpt DOM intact on failure or cancellation. Selecting the active Timeline button is a no-op. The committed transition refreshes pagination after retiring excerpt suppression and restores deferred session analysis asynchronously. Summary failures expose a local retry; request identity prevents stale summaries from replacing another session. Query/scope changes retire active evidence regardless of whether its session context is currently visible. / 呈现切换复用 Continue 的受归属保护前缀加载转换，失败或取消时保持摘录 DOM；重选当前 Timeline 按钮不改变状态。提交转换后解除摘录分页抑制，重新计算分页，并异步恢复延迟会话分析。概况失败提供局部重试，请求身份防止旧概况覆盖其他会话。查询／范围变化无论原会话上下文当前是否可见，都退出活动证据模式。

## Excerpt positions / 摘录位置

The shared excerpt renderer accepts location metadata only for `search_projection` with positive safe-integer coordinates, a hit inside the excerpt range, and a range length consistent with the displayed text's logical lines. It renders the localized metadata inside the disclosure, outside the text viewport. The highlight engine skips that metadata, so line numbers cannot become evidence bindings. This uses existing history payloads without changing the service protocol or deriving positions from rendered Markdown or manual snippets. / 共享摘录 renderer 仅接纳 search_projection 的位置元信息，要求正安全整数坐标、命中位于摘录范围内，且范围长度与展示文本的逻辑行数一致。本地化元信息位于折叠区内、文本滚动区外。高亮引擎跳过它，防止行号成为证据绑定。复用现有历史载荷，不修改服务协议，不从渲染 Markdown 或手动片段推导坐标。

## Boundary / 边界

The history service reuses source adapters, canonical Logical Events, ProjectQueryStore projections and Structured Detail. Its CLI and dedicated HTTP surface share one read service. The browser's mutable active source/project is never used as a retrieval context. A headless instance fixes one source/root/project and indexes once at startup. Restart explicitly to discover later history. / 历史服务复用 source adapters、规范逻辑事件、ProjectQueryStore 投影及结构化详情。CLI 与独立 HTTP 入口共享读取服务。浏览器可变的活动来源／项目不作为检索上下文。Headless 实例固定一个来源／根／项目，在启动时索引一次；明确重启以发现后续历史。

Candidate discovery uses compact query projections. Context/read materialize only selected sessions and share materialization within one request; later requests verify sources again. The service introduces retrieval projections, not canonical events, inferred decision states or new transcript parsers. Existing UI hit counts, snippets, file-filter meaning and Raw Reference ownership remain intact. / 候选发现使用紧凑查询投影；context/read 仅物化选定会话，在同一请求内共享物化结果；后续请求重新核验来源。服务新增检索投影，不新增规范事件、推测决策状态或转录解析器。保持既有 UI 命中计数、摘录、文件筛选含义和 Raw Reference 归属。

## Identity and scope / 标识与范围

Evidence references encode a versioned source/project/session/event locator plus the admitted source snapshot identity. Validate decoded shape and project/source membership before materialization; adapters verify source evidence during materialization. Obtain file paths only from admitted index metadata, never from arbitrary reference payload paths. Re-resolve events by identity, never by filtered `timelineIndex`. Incompatible source changes invalidate old evidence instead of rebinding a position. Context references bind to the running instance; pagination cursors additionally bind to operation parameters. Changing filters requires a new pagination sequence, while restarting expires the context. / 证据引用编码版本化来源／项目／会话／事件定位及准入来源快照标识。物化前验证解码形状及项目／来源归属，adapter 在物化期间核验来源证据。仅从准入索引 metadata 获取文件路径，不能读取引用载荷的任意路径。按身份重定位事件，不用筛选后的 `timelineIndex`。不兼容来源变化使旧证据失效，不将位置重新绑定。上下文引用绑定运行实例；分页游标另外绑定操作参数。改变筛选需开始新的分页序列，重启则使 context 过期。

Self-contained evidence locators can be reverified after restart. They depend on accessible source artifacts and matching event interpretation; they are not global IDs, cryptographic attestations or immutable content archives. The explicit open operation wraps a validated locator in a viewer URL whose reachability depends on the running service. Conservative invalidation is preferable to reading a different event. / 自包含证据定位符可重启后重新核验，依赖可访问来源工件和一致的事件解释；它们不是全局 ID、加密证明或不可变归档。显式 open 操作将核验后的定位符包装为查看 URL，其可达性依赖运行中的服务。保守失效优于读到其他事件。

Compact `er2` locators carry 132-bit SHA-256 prefixes for scope, session, snapshot and event identity; resolution checks collisions instead of choosing an arbitrary match. They need no process-local handle table to survive a restart. Older `er1` locators remain readable. Range locators also preserve navigation direction: backward pages consume a range's suffix when callers reduce the limit, so earlier unread events remain under `previous`. / 紧凑 `er2` 定位符携带范围、会话、快照和事件身份的 132 位 SHA-256 前缀；解析时检查碰撞，不任意选择匹配项。它们不依赖进程内句柄表即可跨重启读取。旧 `er1` 引用仍可读。范围定位符另外保留导航方向：调用方减小 limit 时，向前翻页从范围末尾读取，使更早未读事件继续留在 `previous` 中。

## Disclosure and ordering / 披露与顺序

History consumes both string and replayable decoded-parts query text. `history-search-text.js` keeps a bounded normalized chunk, query-width overlap and original UTF-16 offsets for OR/NOT matching and `match.terms`; it preserves whole-string Unicode lowercasing, including expanding characters and contextual final sigma, across storage boundaries. A forward-only lookahead handles arbitrarily long case-ignorable runs without buffering them. Raw retrieval hints also cross parts. Excerpts retain three lines on either side and at most 360 code units per displayed line, with the hit line cropped around its original offset. Neither candidate scans nor excerpts join an entire disk-backed text. Closing the service disposes its private query store. / History 同时消费字符串与可重放的已解码分块查询文本。`history-search-text.js` 为 OR／NOT 匹配及 `match.terms` 保留有界规范化块、查询宽度的重叠及原始 UTF-16 偏移；跨存储边界保持完整字符串 Unicode 小写语义，包括字符展开与上下文相关词尾 sigma。单向前瞻处理任意长的大小写可忽略字符序列，不缓存该序列。Raw 检索提示同样跨块匹配。摘录保留命中行前后各三行，每展示行最多 360 个码元，命中行围绕原始偏移裁剪。候选扫描与摘录均不拼接完整落盘文本。关闭服务时释放其私有查询存储。

Search yields bounded event candidates. Default diversity ordering compares `(eligible event ordinal within session, session rank)`; grouped `order=session` compares the reversed pair. Session rank is fixed by newest update and ID. Ordinals are assigned after all candidate predicates and artifact exclusion, so an excluded echo never takes another session's place. Signed query cursors carry the last returned pair; filtering against that pair and retaining only the best `limit + 1` candidates bounds retained text independently of total matches or page depth. Changing output budgets cannot consume a candidate that was omitted from the response. / 搜索返回有界事件候选。默认会话覆盖排序比较 `(会话内合格事件序号, 会话排名)`；分组模式 `order=session` 比较反向二元组。会话排名由最近更新及 ID 固定。序号在全部候选筛选与工件排除后分配，因此被排除回声不占据其他会话的位置。签名查询游标携带最后返回的二元组；按该位置过滤，仅保留最佳 `limit + 1` 个候选，使保留文本不随总命中或翻页深度增长。改变输出预算不会消耗未返回的候选。

A `session` restriction resolves only against this instance's indexed Session map and is part of the cursor query digest; it never changes UI state or the service's project/source. Match counts describe the complete scoped query and are independent of output order. Sophisticated relevance ranking remains deferred. Search text is a literal clue, not a Boolean DSL. The existing `file` filter remains a broad recorded association (including transcript/Raw paths), not proof of a write. / `session` 限定仅在当前实例的已索引会话表中解析，并纳入游标查询摘要；不改变 UI 状态或服务项目／来源。命中计数描述完整限定查询，与输出顺序独立。复杂相关性排序仍后置。搜索文本是字面线索，不是布尔 DSL。既有 `file` 筛选仍为广义已记录关联（含转录／Raw 路径），不证明写操作。

Context uses the U−/A−/H/A+/U+ rule from the [product contract](../product-specs/history-retrieval.md). The complete session order supplies boundaries even when a search filters to failures or tools. Ordered intervals between displayed anchors become expandable gaps; previous/next range references reach the remaining prefix/suffix without wrapping. Neighboring records establish adjacency only. Sources may expose explicit session relationships, but context never silently concatenates sessions. / 上下文采用[产品契约](../product-specs/history-retrieval.md)的 U−/A−/H/A+/U+ 规则。即使搜索只筛失败或工具，也由完整会话顺序确定边界。展示锚点之间的有序区间成为可展开间隙；previous/next 范围引用无循环地访问其余前缀／后缀。邻近记录仅证明邻近。来源可提供明确会话关系，但上下文不悄悄拼接会话。

Readable excerpts preserve line structure when available and declare whether their basis is a message, request, result or search projection. Raw reads retain source traceability. Byte accounting must include the serialized envelope and UTF-8 content, preserve valid JSON, and expose continuation rather than silently losing omitted items. Tiny budgets may be rejected when even the envelope cannot fit. / 可读摘录在可用时保留行结构，说明依据为消息、请求、结果或搜索投影。Raw 读取保留来源追溯。字节核算需包含序列化外层及 UTF-8 内容，保持有效 JSON，并通过续读暴露省略项。预算小到外层都无法容纳时可以拒绝。

## Compact transport projection / 紧凑传输投影

`history-presentation.js` owns a per-service bounded handle map (50,000 entries). Handles contain a random instance namespace and must be resolved with the current `contextRef`; durable evidence still passes the original scope, snapshot and source checks. Capacity exhaustion is explicit and full presentation remains usable. No canonical identity is replaced. / `history-presentation.js` 管理每服务有界句柄映射（50,000 项）。句柄包含随机实例命名空间，必须带当前 `contextRef` 解析；持久证据仍通过原有范围、快照和来源核验。容量耗尽明确报错，完整呈现仍可使用；不替换规范身份。

Budget admission projects each candidate prefix before counting bytes. This accounts for shorter references, shared event bodies and coverage reuse rather than rejecting a compact response according to its larger full representation. Final serialized size is checked again with cursor/flags included. Handle allocation is synchronous and service-local; independent readers never mutate active UI state. / 预算准入先投影各候选前缀，再计字节，因而考虑短引用、共享事件正文及覆盖复用，不按较大的完整表示误拒紧凑响应。最后再次检查包含游标／标记的序列化大小。句柄分配同步且服务内局部，独立读取不修改 UI 活动状态。

Context batches share identical event bodies using indexes into one response-local table. Equality includes event identity and excerpt representation; repeated real attempts and different excerpts are not deduplicated. This preserves window ownership and adjacency while reducing overlap. Full-session view and detail text are separate opt-ins; their pagination keys include view/text format to prevent interpreting an offset in another representation. / 批量上下文通过响应内共享表索引复用相同事件正文。相等比较包含事件身份及摘录表示，不去重真实重复尝试和不同摘录；在减少重叠时保留窗口归属与邻近关系。完整会话视图及详情文本分别显式选择，分页键包含视图／文本格式，避免将偏移用在其他表示中。

### Explicit around-hit reads / 显式围绕命中读取

`aroundHit:{before,after}` is an opt-in projection window within the existing read operation. It automatically selects projection and rejects selectors or options that could reinterpret its coordinates. Each selected item resolves the existing event reference and materializes its source through the ordinary validation path, then uses only the reference's stored `h` offset. Zero is valid; an absent offset yields actionable `HIT_OFFSET_UNAVAILABLE`, while an offset outside the verified projection yields `INVALID_REFERENCE`. No MatchRef, term-based position inference or detail/Raw mapping is introduced. / `aroundHit:{before,after}` 是既有 read 操作内显式选择的投影窗口。自动选择 projection，拒绝可能改变坐标解释的选择器或选项。各选定结果项先通过普通路径解析既有事件引用、物化并核验来源，再仅使用引用已保存的 `h` 偏移。零为合法位置；缺少偏移返回可操作的 `HIT_OFFSET_UNAVAILABLE`，超出已核验投影范围则返回 `INVALID_REFERENCE`。不新增 MatchRef，不按术语推测位置，也不映射详情／Raw。

Compute each item's half-open UTF-16 range independently as `[max(0,h-before), min(text.length,h+after+1))`. Return exact offset/endOffset/hitOffset alongside existing text metadata. Previous/next ranges use the requested `before+after+1` width and meet the current range exactly; they are parameters for ordinary absolute projection reads with the same reference, rather than new identities or cursors. Slice boundaries retain code-unit semantics, including surrogate boundaries. Only opted-in responses receive this metadata. / 各项独立计算上述半开 UTF-16 范围，在既有文本 metadata 旁返回准确 offset/endOffset/hitOffset。Previous/next 范围使用请求的 `before+after+1` 宽度，与当前范围准确相接；它们是同一引用的普通绝对投影读取参数，不是新身份或游标。切片边界保持码元语义，包括代理对边界。仅显式选择该模式的响应增加这些 metadata。

The existing per-item loop retains one-request materialization sharing, selected-page-only validation and whole-response byte admission. Its batch cursor binds the normalized aroundHit counts as well as existing reference/part identity; page size and maxBytes may still change. Keeping this inside the read loop avoids recursive read orchestration that would repeat validation or alter batch failure and admission semantics. Ordinary read cursor keys remain unchanged. Accepted-prefix freshness, restart verification and compact-handle resolution remain upstream of slicing. / 既有逐项循环保留请求内物化共享、仅核验当前页结果项及整响应字节准入。批量游标在既有引用／part 身份之外绑定归一化 aroundHit 计数；仍可更改页大小和 maxBytes。将逻辑留在读取循环中，避免递归 read 编排重复核验或改变批量失败与准入语义。普通 read 游标键保持不变。已接受前缀的新鲜度、重启核验及短句柄解析仍先于切片执行。

### Operation-specific recovery messages / 操作专属恢复消息

Recovery advice stays in the existing error message rather than introducing a retry protocol. CLI validation explains single-valued options and the open field whitelist; service failures choose advice from the validated operation and read/context mode. Text reads, around-hit reads, Raw-link pagination and context windows have different legal controls. Metadata-only failures are separate from item-admission failures, and grouped-search outer budgets remain distinct from per-group budgets. / 恢复建议保留在既有错误消息中，不引入重试协议。CLI 校验解释单值参数及 open 字段白名单；服务按经校验的操作与 read/context 模式选择建议。文本读取、命中附近读取、Raw 链接分页及上下文窗口各有不同的合法控制参数。仅元数据超预算与结果项准入失败分别处理，分组搜索外层预算仍与组内预算区分。

Only diagnostics change: selection, byte admission, cursor keys and source verification keep their existing behavior. Advice about changing cursor-bound fields must tell callers to restart without the old cursor. Synthetic tests exercise failure followed by a valid repair; they do not establish that agents choose the repair reliably. / 仅改变诊断：选择、字节准入、游标键与来源核验保留既有行为。建议修改游标绑定字段时须说明去掉旧游标重新请求。合成测试覆盖失败及后续合法修正，不证明 agent 能稳定选择该修正。

## Direct retrieval echoes / 直接检索回声

Search first applies the requested layer and predicates to compact projections. Only sessions with potentially classifiable matching calls/results receive the Raw retrieval-hint scan and, when indicated, source materialization. Unrelated stale sources therefore cannot block matching evidence in another session. Classification can still add cost when a matching session also mentions this tool in documentation. DeepSeek compact Raw records currently cannot support this classification and expose a coverage gap. / 搜索先对紧凑投影应用所选层及筛选条件。只有存在可分类候选调用／结果的会话才扫描 Raw 检索线索，并在需要时物化来源。因此无关失效来源不会阻断另一个会话的匹配证据。匹配会话同时在文档中提及本工具时，分类仍可能增加成本。DeepSeek 紧凑 Raw 记录当前不能支持该分类，需暴露覆盖缺口。

A conservative recognizer examines structured tool requests for supported direct `session-analyzer history status/search/context/read/open` invocations and links their results using existing call relationships. Producer/operation fields help recognize the output but are not authentication. Unrecognized wrappers and mixed operations remain ordinary evidence. Classifications are retrieval-only, reversible and applied before candidate limits; they do not mutate events or establish that repeated text is independent evidence. / 保守识别器检查结构化工具请求中受支持的直接 `session-analyzer history status/search/context/read/open` 调用，利用既有调用关系关联结果。Producer/operation 字段帮助识别输出，但不是认证。未识别包装和混合操作仍是普通证据。分类仅作用于检索，可逆，先于候选限制应用；不修改事件，也不证明重复文本是独立证据。

## Alternatives and risks / 备选与风险

Adapters verify accepted source prefixes: append-only growth can preserve an existing running snapshot, while changes to indexed bytes fail. New suffixes are absent from old search projections; restart to include them and acquire new snapshot references. / Adapter 核验已接受来源前缀：仅追加增长可以保留运行中快照，而已索引字节变化会失败。旧搜索投影不包含新后缀；需重启纳入并获取新快照引用。

- Reusing `/api/source` and `/api/project` was rejected: concurrent readers would change user UI state. Fixed instances cost another process but isolate scope simply. / 拒绝复用 `/api/source` 和 `/api/project`：并发读取会改变用户 UI 状态。固定实例增加进程，但以简单边界隔离范围。
- A fresh index per command was rejected because progressive disclosure needs several cheap calls. Automatic daemons are deferred to avoid hidden lifecycle/configuration changes. / 拒绝逐命令建索引，因为渐进披露需要多次低成本调用。自动 daemon 后置，避免隐式生命周期／配置变化。
- Vector search, summarization and semantic segment classification are deferred until failure evidence shows they are needed; lexical retrieval can miss vocabulary changes and must disclose its scope. / 向量搜索、摘要及语义分段分类后置，等待失败证据证明必要性；词法检索可能漏掉术语变化，必须声明范围。
- Full shell parsing for echoes risks suppressing real development evidence. Narrow admission deliberately leaves some direct echoes and all unproven paraphrases searchable. / 完整 shell 回声解析有误删真实开发证据风险。窄准入有意保留部分直接回声及所有未获证明的转述。
- Snapshot checks detect source changes but do not retain removed history. Output budgets bound transfer, not necessarily indexing cost or the memory needed to materialize a large selected session. / 快照检查发现来源变化，但不保存已删除历史。输出预算约束传输，不必然约束索引成本或大型选定会话物化所需内存。

See [evaluation protocol](../evals/history-retrieval/README.md) for isolated, synthetic evidence-based tasks and honest reporting requirements. / 关于隔离、基于合成证据的任务及如实报告要求，参见[评估协议](../evals/history-retrieval/README.md)。

## Convergence increment / 收敛增量

Grouped search is orchestration around the existing projection scan, not a new ranking system. Each group executes independently; query cursors additionally bind its ID and existing predicates, while queryIdentity fingerprints the supplied query definition without cursor or output budgets. Per-group response admission is followed by whole-envelope admission; omitted results retain their original input cursor and never consume invisible candidates. This initial implementation may rescan projections for each group and makes no scan-latency reduction claim. Query warnings are distinct from reusable static coverage warnings. / 分组搜索编排已有投影扫描，不新增排序系统。各组独立执行；查询游标额外绑定组 ID 和既有条件，queryIdentity 指纹包含所给查询定义但不含游标或输出预算。组内准入后再检查整批外层，省略结果保留原输入游标，不消费不可见候选。首版可能逐组重复扫描投影，不宣称降低扫描时延。查询警告与可复用的静态覆盖警告分离。

`history-source-locator.js` derives admitted uncompressed primary-file snapshots from Codex dependency metadata. Compression admission uses the dependency's recorded file identity: a canonical `.jsonl` path can represent a physical `.jsonl.zst` artifact and cannot establish storage format. sr1 includes a scope digest, canonical indexed path and version digest of accepted-byte/record evidence and file identity. It never opens an input path; it selects only existing indexed Sessions, verifies through normal materialization, then maps sourceLocator physical lines to Raw Records and existing rawRefs to all explicit Logical Event associations. Canonical relative paths and index-derived absolute aliases are admission facts; only indexed names are normalized for comparison with slash-normalized canonical Raw locators. Logical associations and Raw matches have independent continuation bounds in read. / history-source-locator.js 从 Codex 依赖 metadata 推导准入的未压缩主文件快照。压缩准入依据依赖中记录的文件身份：规范 `.jsonl` 路径可以表示物理 `.jsonl.zst` 工件，不能证明存储格式。sr1 包含范围摘要、规范索引路径，以及已接受字节／记录证据和文件身份的版本摘要。它不打开输入路径，只选择已有索引会话，经正常物化核验，再按 sourceLocator 物理行定位 Raw，并沿现有 rawRefs 找全部明确逻辑关联。规范相对路径和索引推导绝对别名是准入事实；只对索引名称规范化以比较使用斜杠的规范 Raw 定位。read 中逻辑关联与 Raw 匹配分别有续读边界。

An old path with no version cannot be certified retroactively. Source snapshot verification is about stored evidence, not historical claim truth or current code validity. MatchRef and semantic state labels remain deferred; the evaluation analyzer measures known hit positions rather than inventing range identities or supported conclusions. / 无版本旧路径不能被追溯认证。来源快照核验关注存储证据，不证明历史主张真实或当前代码有效。MatchRef 及语义状态标签继续后置，评估器量测已知命中位置，不编造范围身份或结论支撑。

## Planned source observation, not implemented / 来源观察规划，尚未实现

The first planned observer is Codex-only and explicitly requested, separate from fixed-snapshot `status` and ordinary evidence verification. Its report must distinguish metadata-only observations, unknown portions and partial failures; no command or request fields are specified yet. Report scope and observation intervals, not a combined fresh/stale verdict. Unchanged metadata cannot prove unchanged content, current project coverage or valid historical claims. Keep strict selected-source reads and the existing snapshot, references, cursors and Web URLs unchanged. / 首个规划观察器仅针对 Codex，由调用方显式请求，与固定快照 `status` 和普通证据核验分开。报告必须区分仅 metadata 的观察、未知部分及部分失败；目前不指定命令或请求字段。报告范围及观察时段，不合成 fresh/stale 判定。metadata 未变不能证明内容未变、项目覆盖最新或历史主张有效。保持严格的选中来源读取，以及既有快照、引用、游标和 Web URL。

“Since indexing” requires a discovery inventory frozen while constructing that snapshot, including unadmitted candidates, per-item observation intervals and enumeration gaps. Discovery and file indexing span separate intervals; `indexedAt` is not an atomic filesystem snapshot, and changes during those intervals retain uncertainty. Existing admitted dependencies and aggregate counts are not that inventory. Without a matching baseline, newly observed paths are only candidates outside the snapshot with unknown prior existence. Project membership needs source evidence, potentially later cwd records or history dependencies; directory membership and stat are insufficient. Reuse adapter discovery rules and scope without invoking a complete index build as a metadata check. / “索引后变化”需要在构建该快照时冻结发现清单，包括未准入候选、逐项观察时段及枚举缺口。发现与文件索引各有时段；`indexedAt` 不是文件系统原子快照，期间变化保留不确定性。现有准入依赖与汇总数量不等于此清单。缺少匹配基线时，新观察到的路径仅为快照外候选，原先是否存在未知。项目归属需要来源依据，可能涉及后段 cwd 记录或历史依赖；目录归属与 stat 均不足。复用 adapter 发现规则及范围，不以完整建索引冒充 metadata 检查。

Observe each physical dependency once and preserve all owning-session associations. Separate stored physical metadata from accepted logical boundaries: Codex compressed byte offsets describe decoded records, ancestor suffixes can already be excluded at indexing, and other adapters can retain only committed prefixes before torn tails. Physical growth alone cannot establish append-only change or new searchable project evidence. Include admitted archived dependencies without treating archives as standalone heads; list unexamined current-head pointers, copied/control metadata and history relationships explicitly. Enumeration failures or concurrent changes leave the affected scope unknown. / 每个物理依赖只观察一次，保留全部所属会话关联。分别保存物理 metadata 与接纳的逻辑边界：Codex 压缩字节偏移描述解压记录，祖先后缀可能在索引时就已排除，其他 adapter 可能仅保留未完整写入尾部之前的已提交前缀。仅有物理增长不能证明仅追加变化或新增可搜索项目依据。包含准入的归档依赖，但不把归档作为独立头；明确列出未检查的当前头指针、复制／控制 metadata 和历史关系。枚举失败或并发变化使受影响范围保持未知。
