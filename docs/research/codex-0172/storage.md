## Attached threads, Side Chat and Guardian

* `30587d7885` introduces attached forks and `766f5473f2` changes their history presentation. `app-server/src/request_processors/thread_processor.rs:5504–5525,5604,5899`, `thread-store/src/local/create_thread.rs:48`, `local/live_writer.rs:40–73`, `protocol/src/protocol.rs:3555–3566` and `rollout/src/list.rs:1031–1034` trace the request to an **owned** `session_meta.attached_thread=true` and `forked_from_id`. The returned `attachedToThreadId` is a view of the relation. `rollout_lineage.rs:340–392` projects child-visible pages separately from the inherited model context. A generic attached child can have any feature source. The real corpus contained two attached files with VS Code creation source. Neither establishes TUI Side Chat.
* `57e64682f8`, `tui/src/app_server_session.rs:219,1392–1449,1545–1562`: the local workspace may request a persisted paginated attached fork marked `tui_side_chat`. The fallback can be ephemeral. `context-fragments/src/side_conversation.rs:68–101` builds two pre-turn records, a developer policy and a user-role boundary. `tui/src/app_server_session/side_chat_history.rs:19–49` checks the child's physical prefix, roles, marker and order. Text matching without that context would misclassify a user's quotation.
* Analyzer `src/codex.js:1654–1684,1715–1753,4624–4641` admits the fork source. It lacks an independent attached relation and its message classification counts the bootstrap boundary as user input in the reproduction. Ordinary parent, fork and existing subagent/review detection have separate evidence. Preserve them. Navigation for the new relation can ship independently of the incorrect count.
* `core/src/codex_delegate.rs:96–107,136–144` sets subagent session source, explicit parent, and `guardian_review` or `subagent`. `protocol/src/protocol.rs:3263–3279` serializes the source. `07316174c6` adds forwarded private events, which `rollout/src/policy.rs:188–228` excludes. The corpus contains 283 primary headers classified `guardian_review` and 268 canonical enter/exit pairs (268 of each, not a pairing proof). A Guardian safety review and a code-review lifecycle should not share inferred ownership based on time alone. Existing `test/codex-fork-review-markers.test.js`, `test/codex-subagent-prefix.test.js` and `test/codex-turn-lineage.test.js` remain controls. A Guardian-specific label is optional. No fresh Guardian writer was triggered.

## Writer experiment

Run `python scripts/audit-codex-0172-writer.py <native-codex-0.172.0-executable>` with Node available. The script creates a one-use home/project, configures only a loopback Responses provider and returns counts. The official executable runs the actual local writer, with simulated model output. It exercises start, normal turns, fork, inject, revert and resume. The minimized injected policy and boundary simulate a client. This does not exercise the TUI itself. The script requires neither upstream sources nor a model-service account.

| Input | App Server and disk | Analyzer after writer shutdown |
| --- | --- | --- |
| Ordinary Legacy | Parent and copied fork, no ordinals. `attachToSource:true` rejected with RPC `-32600`. | Parent has one user message, empty continuation has zero. |
| Ordinary Paginated | Parent ordinal 0, fork header at ordinal 14. Revert of one added mock turn produced another physical child artifact. Resume returned the same thread ID. | Both builders indexed the same logical fork. Zero Main hits for the reverted text. |
| Attached without TUI source | Attached metadata plus real fork/base identity, two physical rows. | Fork link present, no independent typed attachment relation. No phantom user input. |
| Attached with TUI source + imported bootstrap | Two minimized pre-turn messages followed by one real mock-provider turn. | Uncompacted resident, compact resident, cold source-backed and reindex with previous index each yielded three Main events, two user messages and one Main search hit for the bootstrap boundary. Expected one authored user question, one assistant answer and physically reachable bootstrap evidence. |

Two more threads provided external-audio controls, one per history mode. The native writer rejected direct file IDs with RPC `-32600` and completed a valid inline WAV request. Each caption had 1/0/2 Main/Protocol/Raw hits. The eight logical threads occupied nine physical files. Cold source diagnostics were empty. On this chained dataset the reindex returned a distinct sessions array. This last run exercises reindex, not proven whole-index warm reuse. The synthetic message/operation controls separately verify reuse. One preliminary read before writer shutdown omitted newly created child Sessions. No matched diagnostic or fixed concurrent snapshot was captured on that preliminary run; it is not classified as a live-reader defect.
