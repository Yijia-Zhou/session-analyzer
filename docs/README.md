# Documentation Overview

This repository uses three document classes:

- `product-specs/`: what the product should do
- `design-docs/`: why the system is designed this way
- `exec-plans/`: how a concrete change is being executed

## How to use this tree

- Start with a product spec when adding or changing user-facing behavior.
- Add or update a design doc when changing the transcript model, APIs, storage, or UI architecture.
- Create an exec plan for any non-trivial implementation that spans multiple files or milestones.
