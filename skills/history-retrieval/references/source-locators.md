# Read a known source position

When `sourceLocators` is available and a note already identifies an indexed uncompressed Codex transcript and physical line, read it directly with `read --input '{"source":{"sourcePath":"<exact indexed path>","locator":{"type":"jsonl-line","line":3}}}'`. This defaults to Raw content and returns explicit `logicalRefs` for optional context. Save `source.sourceRef` and use it instead of `sourcePath` on subsequent reads to bind the accepted snapshot. Legacy path+line returns `unverified_legacy_locator`: current scope membership does not verify what the old note meant. Raw evidence must still be inspected. No arbitrary file path or unsupported source is read.

Supply the exact indexed path spelling or its exact indexed absolute alias, including platform separators.

Admission currently comes from each Session's uncompressed Codex primary transcript. Historical dependencies or archived ancestors can contribute searchable events without being admitted through their old path/line. `UNKNOWN_SOURCE` from this entrypoint does not establish that the evidence is absent; use canonical search/context/read references to check it.

Association continuation returns a complete `logicalRefsNext` read input with the offset in `source.logicalOffset` and the originating Raw's durable reference in `source.rawRef`. A physical location can match several Raw Records; use the item's returned request to keep its identity. Top-level `next` pages the Raw batch. Text continuation returns a part's complete `next` input, using UTF-16 `offset`. Save any of these inputs as compact UTF-8 JSON and submit it unchanged with `read --input-file <path>`. Versioned SourceRef input reports `source_snapshot_verified` only after source validation; saving a SourceRef never retroactively validates the legacy note.
