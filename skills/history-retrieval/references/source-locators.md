# Read a known source position / 读取已知来源位置

When `sourceLocators` is available and a note already identifies an indexed uncompressed Codex transcript and physical line, read it directly with `read --input '{"source":{"sourcePath":"<exact indexed path>","locator":{"type":"jsonl-line","line":3}}}'`. This defaults to Raw content and returns explicit `logicalRefs` for optional context. Save `source.sourceRef` and use it instead of `sourcePath` on subsequent reads to bind the accepted snapshot. Legacy path+line returns `unverified_legacy_locator`: current scope membership does not verify what the old note meant. Raw evidence must still be inspected. No arbitrary file path or unsupported source is read. / 能力包含 `sourceLocators`，且笔记已有已索引未压缩 Codex 转录及物理行时，使用上述 `read --input` 直接读取。默认返回 Raw 内容，`logicalRefs` 提供可选上下文的明确关联。保存 `source.sourceRef`，后续以其代替 `sourcePath` 绑定已接受快照。旧路径／行号返回 `unverified_legacy_locator`：当前范围归属不验证旧笔记所指内容，仍需检查 Raw 证据。不读取任意文件或未支持的来源。

Supply the exact indexed path spelling or its exact indexed absolute alias, including platform separators. / 提供精确索引路径写法或精确索引绝对别名，包括平台分隔符。

Admission currently comes from each Session's uncompressed Codex primary transcript. Historical dependencies or archived ancestors can contribute searchable events without being admitted through their old path/line. `UNKNOWN_SOURCE` from this entrypoint does not establish that the evidence is absent; use canonical search/context/read references to check it. / 此入口目前从各会话未压缩的 Codex 主转录建立准入。历史依赖或归档祖先可以贡献可搜索事件，但其旧路径／行号未必被此入口准入。这里的 `UNKNOWN_SOURCE` 不证明证据不存在，应通过规范的搜索／上下文／读取引用核对。

Association continuation uses `logicalRefsNextOffset` as `source.logicalOffset`. Text continuation uses a part's `nextOffset` as top-level `offset`; both may need continuation and use different coordinate spaces. Versioned SourceRef input reports `source_snapshot_verified` only after source validation; saving a SourceRef never retroactively validates the legacy note. / 关联续读以 `logicalRefsNextOffset` 作为 `source.logicalOffset`。文本续读以部分的 `nextOffset` 作为顶层 `offset`；两者可能均需续读，且坐标空间不同。版本化 SourceRef 输入通过来源核验后才报告 `source_snapshot_verified`；保存 SourceRef 不追认旧笔记。
