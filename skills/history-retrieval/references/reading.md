# Reading and continuation / 阅读与续读

Read when expanding context, selecting parts, or continuing bounded output. / 展开上下文、选择部分或续读有界输出时阅读。

Commands return JSON. Use repeated `--ref` for batches and `--max-bytes` to control response size. Pass returned cursors and context exactly; use operation help for supported continuation flags. Evidence refs and ephemeral context refs have different lifetimes. If a source changed, search again; never substitute an old event position. / 命令返回 JSON。重复 `--ref` 可批量处理；`--max-bytes` 控制响应大小。原样传递返回游标与 context；续读参数见各操作 help。证据引用与临时上下文引用生命周期不同。来源变化后重新搜索，不替换为旧事件位置。

## Context and full views / 上下文与完整视图

Compact context stores event bodies once in top-level `events`; each window's `eventIndexes` and `anchorIndexes` index that array. Do not expect `items[].events` in this mode. Shared bodies do not merge sessions or assert causality. Choose one promising anchor before expanding several overlapping windows. / 紧凑上下文只在顶层 `events` 保存一次事件正文；各窗口的 `eventIndexes`、`anchorIndexes` 索引该数组，此模式没有 `items[].events`。共享正文不合并会话，也不声明因果。展开多个重叠窗口前，先选一个有价值的锚点。

Choose nearby context or full-session pagination explicitly. Context `--length` is valid only with `--view full`. `--presentation compact` controls response structure and references independently of `--view full`, which selects bounded transcript content. / 明确选择邻近上下文或完整会话分页。context 的 `--length` 仅在 `--view full` 时有效。`--presentation compact` 控制响应结构和引用，与选择有界转录正文的 `--view full` 相互独立。

```sh
# Nearby message anchors / 邻近消息锚点
session-analyzer history context --endpoint http://127.0.0.1:17891 --context "<contextRef>" --ref "<hit-ref>" --presentation compact --view outline
# Session sequence from the beginning / 从头读取会话序列
session-analyzer history context --endpoint http://127.0.0.1:17891 --context "<contextRef>" --ref "<hit-ref>" --presentation compact --view full --limit 20 --length 2000
# Continue the returned window / 继续返回的窗口
session-analyzer history context --endpoint http://127.0.0.1:17891 --context "<contextRef>" --ref "<returned-next-ref>" --presentation compact --view full --limit 20 --length 2000
```

When required evidence is still missing, first follow returned continuation information if a promising candidate's supporting passage is not yet shown. If the original rationale is missing but implementation or acceptance messages are nearby, inspect available `previous`/gap context. Prefer these concrete leads over repeating broad searches; choose continuation or a more precise query to fill the remaining gap directly. Stop once the user's requested judgment has sufficient support; this does not require a fixed search → outline → gaps → read sequence, clearing every `hasMore`, or reading the whole Session. / 必需证据仍缺时，若有价值候选的支持段尚未显示，优先沿返回续读信息补读。缺少原始理由但附近有实施或接受方案的消息时，核对已有 `previous`／间隙上下文。优先利用这些具体线索而非重复宽泛搜索；可选续读或更精确的 query，直接补齐剩余缺项。所需判断已有充分支撑即可停止，不必固定按 search → outline → gaps → read 执行、清空所有 `hasMore` 或读完整会话。

The initial anchor may be outside the first full page. For long event text, use excerpt `nextOffset` with `read --parts projection`. `read --text-format text` removes exact duplicate code/terminal/JSON renderings within one event; unsupported renderers remain explicitly structured. / 初始锚点可能不在完整视图第一页。长事件正文使用摘录的 `nextOffset` 配合 `read --parts projection` 续读。`read --text-format text` 去除同一事件内完全重复的代码／终端／JSON 呈现；未支持的 renderer 保持明确结构。

Batch independent context/read refs in one call. A gap exposes its event count; when the whole operation sequence matters, use `context --ref <gap> --limit 20` (up to 100) with a suitable byte budget and inspect its `next` until the gap is covered. `hasMore` concerns the batch, not internal gaps. Parse returned refs programmatically when possible instead of retyping them. For a long hit, `excerpt.hitOffset` is a UTF-16 offset for `read --parts projection --offset <offset>`; it is not a Raw source coordinate. / 将独立的 context/read 引用合并为一次批量请求。间隙给出事件数量；需要完整操作序列时，可用 `context --ref <gap> --limit 20`（最多 100），配置合适字节预算，并沿 `next` 覆盖剩余间隙。`hasMore` 表示批量分页，不表示内部间隙已经读完。尽量程序化提取返回引用，避免手工重抄。长命中的 `excerpt.hitOffset` 可作为 `read --parts projection --offset <offset>` 的 UTF-16 偏移；它不是 Raw 来源坐标。

Main context uses message anchors; Protocol/Raw use layer-local neighbors. / Main 上下文使用消息锚点；Protocol／Raw 使用层内邻近事件。

## Output budget recovery / 输出预算恢复

`OUTPUT_BUDGET_TOO_SMALL` concerns serialized UTF-8 JSON bytes; text `--length` counts UTF-16 code units. Narrow a read to useful parts (for example `projection`) and a smaller `--length`, or a smaller `aroundHit` window around the actual stored hit. Context full pages/gap ranges can use a smaller `--limit`; only full view permits `--length`. A nearby outline window may need a focused read instead. Read `--limit` also bounds Raw-link/association lists. If metadata or even the first search hit cannot fit, increase permitted `--max-bytes`; compact presentation with already-read `--context` may reduce repeated metadata. Changing view alone does not guarantee a fit. Check truncation and continuation before treating an excerpt as complete. / `OUTPUT_BUDGET_TOO_SMALL` 涉及序列化 UTF-8 JSON 字节数；文本 `--length` 按 UTF-16 code unit 计。读取可缩小为有用部分（如 `projection`）并减小 `--length`，或缩小围绕实际已存命中的 `aroundHit` 窗口。context 完整视图分页／间隙范围可减小 `--limit`；只有完整视图允许 `--length`。邻近 outline 窗口可能需要改为聚焦读取。read 的 `--limit` 也限制 Raw 链接／关联列表。元数据或首个搜索命中仍放不下时，增大允许的 `--max-bytes`；compact 呈现配合已读的 `--context` 可能减少重复元数据。仅改变 view 不保证放得下。把摘录视为完整内容前，检查截断和续读。

After changing parts, `aroundHit`, text length or context view, restart the selected refs without the old batch `--cursor`, then follow the new continuations. Page size and byte budget may change during continuation. / 改变 parts、`aroundHit`、文本长度或 context view 后，用选定引用去掉旧批量 `--cursor` 重新请求，再沿新返回的续读信息继续。续读时可改变页大小和字节预算。

## Read around a stored hit / 围绕已存命中读取

When `status.capabilities.aroundHit` is available, `read --input '{"refs":["<returned-hit-ref>"],"aroundHit":{"before":800,"after":1600}}'` automatically selects search projection. Both counts are required nonnegative safe integers in UTF-16 code units; `before + after + 1` must be at most 100000. An explicit `parts` list may normalize only to `["projection"]`. Do not combine `aroundHit` with `source`, `offset`, `length` or `textFormat`. / `status.capabilities.aroundHit` 可用时，上述命令自动选择搜索投影。两个计数均须为非负安全整数，单位为 UTF-16 code unit；`before + after + 1` 不超过 100000。显式 `parts` 仅能规范化为 `["projection"]`。不得与 `source`、`offset`、`length` 或 `textFormat` 同用。

The ref must retain a stored hit offset; zero is valid. `HIT_OFFSET_UNAVAILABLE` means no such anchor is available: search again or choose an explicit ordinary projection read, never guess the hit. Each batched ref gets its own window. The part retains `offset`, `totalLength`, `nextOffset`, `text`, `truncated` and adds `hitOffset`, exclusive `endOffset`, and `previous`/`next` ranges (`{offset,length}` or null). Continue with ordinary `read {refs:[sameRef],parts:["projection"],...range}` using the returned range unchanged. These coordinates refer only to the original search projection, never message/request/result or Raw text. Top-level cursor still pages items and remains bound to the original aroundHit request. Compact `evidenceRef` preserves the original hit anchor for citation. / 引用须保留已存命中偏移；零有效。`HIT_OFFSET_UNAVAILABLE` 表示没有该锚点：重新搜索或明确选择普通投影读取，不猜命中。批量中每个引用各有窗口。部分保留 `offset`、`totalLength`、`nextOffset`、`text`、`truncated`，新增 `hitOffset`、不包含端点的 `endOffset` 和 `previous`／`next` 范围（`{offset,length}` 或 null）。按上述普通 read 形式原样使用返回范围续读。坐标仅属于原搜索投影，不映射到消息／请求／结果或 Raw 文本。顶层 cursor 仍用于项分页，绑定原 aroundHit 请求。紧凑 `evidenceRef` 保留原命中锚点供引用。

## Detail text, Raw links and offsets / 详情文本、Raw 链接与偏移

With the default `textFormat=structured`, available message/request/result parts use `structured_detail_json` and may include rendered HTML. With `--text-format text`, they use `detail_text`; unsupported detail types remain represented as JSON. Both are detail projections, not verbatim source text. Use `--parts projection` for readable search text or Raw reads for original records. For durable citations, save compact read's `items[].evidenceRef` or full read's persistent `items[].ref`. / 默认 `textFormat=structured` 时，可用的消息／请求／结果部分使用 `structured_detail_json`，可能含已渲染 HTML；使用 `--text-format text` 时返回 `detail_text`，未支持的详情类型仍以 JSON 表示。两者都是详情投影，不是来源原文。可用 `--parts projection` 读取搜索文本，或用 Raw 读取原始记录。保存持久引用时，紧凑 read 使用 `items[].evidenceRef`，完整 read 使用持久 `items[].ref`。

Expand context-window `gaps[].ref`, `previous` or `next` references through `history context --ref <returned-ref>`. For a long part, repeat `read` with its `nextOffset` as `--offset`, optionally reducing `--length`; these text offsets count UTF-16 code units. `--parts raw` on a Logical Event returns Raw refs: read those with `--parts raw` to inspect original JSON. To page a Logical Event's Raw links, use its `rawRefsNextOffset` as `--offset` (here a link index). Top-level `nextCursor` pages batched items with `--cursor` and the original arguments. / 将上下文窗口的 `gaps[].ref`、`previous` 或 `next` 引用传给 `history context --ref <返回引用>` 展开。长内容用其 `nextOffset` 作为 `--offset` 重复 `read`，可减小 `--length`；文本偏移按 UTF-16 code unit 计。对逻辑事件使用 `--parts raw` 返回 Raw 引用，再对这些引用以 `--parts raw` 读取原始 JSON。逻辑事件 Raw 链接分页使用 `rawRefsNextOffset` 作为 `--offset`（此处为链接索引）。顶层 `nextCursor` 通过 `--cursor` 加原参数对批量项翻页。

Repeated parts are deduplicated before offset interpretation. Check `contentTruncated` and each part's `truncated`/continuation as well as top-level `truncated` and `hasMore`: a finished batch can still contain unfinished parts or internal gaps. / 重复 parts 在解释偏移前去重。除顶层 `truncated`、`hasMore` 外，还检查 `contentTruncated` 及各部分 `truncated`／续读；批量结束仍可能有未完成部分或内部间隙。
