# Open selected evidence / 打开选中证据

When capabilities include `open`, hand a selected result to the user with `history open --endpoint <original endpoint> --ref <returned ref> --no-browser`; cite its returned `url` without constructing one. If the user explicitly asks to open the record, omit `--no-browser`. Internal search does not require opening a page. Pass `--context <original contextRef>` for an `hr1` handle. Open accepts one event; expand a range through context first to select one. It prepares a fixed-snapshot viewer independent of ordinary Web state. / 能力包含 open 时，用所列命令把选中结果交给用户核对，引用返回 url，不自行构造。用户明确要求打开记录时省略 no-browser，内部搜索无需打开页面。hr1 句柄带原 context；open 仅接受单事件，范围先通过 context 展开再选择。查看页绑定固定快照，独立于普通 Web 状态。

The `open` API input contains only `refs:[one event reference]` and optional `contextRef`. Omit search/read paging and budget fields such as `maxBytes`; they cause an argument error here. / `open` API 输入仅包含 `refs:[单个事件引用]` 和可选 `contextRef`。不要沿用 search/read 的分页或预算字段，例如 `maxBytes`，否则此操作会报参数错误。

When the user requests original records for checking, verify that delivered reader URLs cover the required evidence; one URL may support several items. A durable evidence ref is not a reader URL, and one valid link does not establish complete coverage. After finding key evidence, leave room for necessary continuation and `open`; finish the requested handoff before exploring optional questions. If budget runs out, identify the evidence or URLs still missing. / 用户要求核对原始记录时，检查已交付的阅读页 URL 是否覆盖必需证据项；一个 URL 可支持多项。持久证据引用不等于阅读页 URL，已有一个有效链接也不代表覆盖完整。找到关键证据后，为必要续读及 `open` 留出余量，先完成所需交付再扩展可选问题。预算不足时，明确仍缺的证据或 URL。

Report `targetVerified`, `viewerReady` and `browserOpenRequested` accurately: browser invocation is not a page-location receipt. If the opener fails, preserve the returned URL and mention the failure. Explain the service environment when its localhost may be remote to the user. Keep the original service running; on stale/scope/context errors, correct the scope or search again rather than guessing an event. The page shows the exact record and hit excerpt; continuous timeline reading is a separate user action. / 准确报告三个状态，浏览器调用不是页面定位回执。启动失败保留返回 URL 并说明失败；localhost 对用户可能位于远端时说明服务环境。保持原服务运行；过期／范围／context 错误时修正范围或重新搜索，不猜事件。页面显示准确记录与命中片段，连续时间线阅读由用户另行进入。

Browser failure retains the ready URL with `browser.status=failed` and CLI exit code 1; `--no-browser` reports `skipped`. None of the three status booleans proves page-render completion. / 浏览器失败保留就绪 URL，返回 `browser.status=failed` 和退出码 1；`--no-browser` 报告 `skipped`。三个布尔状态均不证明页面渲染完成。

Keep the original service running. Refresh revalidates bytes: accepted-prefix appends can remain readable, while rewrite/deletion or a new snapshot can invalidate refs. After restart call open again with durable evidence; the viewer port may change. Loopback belongs to the service environment: remote/container use needs a reachable service or deliberate forwarding. / 保持原服务运行。刷新重新核验字节：已接受前缀后追加可继续读，改写／删除或新快照可能使引用失效。重启后以持久证据再次调用 open；查看端口可能变化。回环地址属于服务环境，远端／容器需服务可达或明确转发。

Linux opening requires GLib `gio` and a registered default HTTP browser; otherwise use the preserved URL or `--no-browser`. Bounded hit/nearby excerpts show omissions; they are neither Raw coordinates nor a continuous timeline segment. / Linux 打开需 GLib `gio` 和已注册默认 HTTP 浏览器；否则使用保留 URL 或 `--no-browser`。有界命中／邻近摘录会标明省略，不是 Raw 坐标或连续时间线片段。
